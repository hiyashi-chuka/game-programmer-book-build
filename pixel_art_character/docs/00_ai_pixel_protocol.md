# 00. AI向けドット絵描画プロトコル（画像生成を使わずに描くための共通ルール）

この資料群（00〜07）は「画像生成モデルを使わず、テキストとコードだけでドット絵キャラクターを描く」ための手引きです。
生成AIに渡すときは **00 を最初に読ませ**、続けて 01〜07 を参照させてください。

---

## 0-1. 基本の考え方

画像生成を使わない場合、AIは「絵」を直接出力できません。代わりに次のどちらかで **ピクセルの座標と色を明示的に決める** ことで絵を作ります。

| 方式 | 内容 | 向いているサイズ |
|---|---|---|
| A. 文字グリッド方式 | 1文字＝1ピクセルのASCII表と、文字→色のパレット表を書く | 〜48×48（顔アイコン、小さなスプライト） |
| B. 図形ラスタライズ方式 | 楕円・多角形・ベジェ曲線をコードで格子に塗り、影や輪郭線をアルゴリズムで付け、最後に目や口などを方式Aで上書きする | 48×64 〜 128×192（全身立ち絵） |

どちらも最後は **PNG に書き出し → 拡大表示して自分の目で確認 → 修正** のループを回します。
「確認せずに完成とする」のは禁止です。必ずレンダリング結果を見て、下の「セルフチェック」を通してください。

### 方式Aのデータ形式（推奨）

```text
PALETTE
. = transparent
K = #3b2a3a  (輪郭・最暗)
S = #ffe3d3  (肌ベース)
s = #f2b8a8  (肌影)
H = #f6d9b8  (髪ベース)
h = #d9a98a  (髪影)
W = #ffffff  (白・ハイライト)

GRID (x→ / y↓)
....KKKK....
..KKHHHHKK..
.KHHHHHHHHK.
.KhHHHHHHhK.
.KSSSSSSSSK.
```

ルール:
- 1行の文字数は全行で同じにする（崩れると絵が壊れる）。
- 大文字＝明るい／ベース、小文字＝影、のように **命名規則を決める** と間違いが減る。
- 左右対称の部分は「左半分だけ書いてミラー」させると効率的。ただし完全対称は不自然なので、髪・表情・ポーズで非対称を加える。

### 方式Bの処理パイプライン（推奨）

1. **ランドマーク表** を作る（頭頂・目・顎・肩・腰・膝・足首などのy座標、幅）→ 01・07参照
2. 各パーツを **マスク（どのピクセルが属するか）** として図形で作る
3. 奥 → 手前の順に **ベタ塗り**（後ろ髪 → 体 → 服 → 腕 → 顔 → 前髪 → 小物）
4. **影**：光源方向にマスクをずらし、ずらした領域からはみ出た部分を影にする（オフセットマスク法、05参照）＋ 落ち影を手で指定
5. **輪郭線**：マスクの境界ピクセルを素材ごとの暗色で塗る（色トレス）。光側は一段明るく（セレクティブアウトライン）
6. **ディテール**：目・眉・口・頬・ハイライトを方式Aのテンプレートで上書き
7. **クリーンアップ**：孤立ピクセル、ギザギザ（ジャギー）、ダブル線の修正
8. 等倍と拡大（×4〜×8）の両方でPNG出力して確認

## 0-2. ドット絵の技術ルール

### 線（ジャギー）のルール
- 直線・曲線は「同じ長さの段」の繰り返しで描く。傾き 1:1、1:2、2:1、1:3 などが綺麗。
- 曲線は段の長さを **単調に** 変化させる：`3-2-1-1-2-3` は良い、`3-1-2-1-3` はガタつく。
- 良い例（緩やかな円弧）:
  ```text
  ....XXXX....
  ..XX....XX..
  .X........X.
  X..........X
  ```
- 悪い例（段の長さがバラバラ）:
  ```text
  ...XXXXX....
  ..X.....XX..
  .X.........X
  X...........
  ```
- **ダブル（2ピクセル幅になった線の角）** を消す。斜め線は角で接するだけにする:
  ```text
  悪い: XX..    良い: X...
        .XX.          .X..
        ..XX          ..X.
  ```

### 色のルール
- 1素材あたりの色数の目安: 肌 3〜4色、髪 4〜5色、服 3〜4色、黒っぽい素材 2色＋輪郭。
- **色相シフト**：影は彩度を少し上げつつ色相を寒色（青・紫）側へ、ハイライトは暖色（黄）側へずらす。単に暗く／明るくしただけの「ストレートランプ」は濁って見える。
- ランプの両端（最明・最暗）は彩度を下げる。そうしないと目に痛い色になる。
- 異なる素材のランプで中間色を **共有** するとパレットがまとまる（例: 肌影と髪の明部を近い色に）。
- 全体のパレットは 16〜32色以内を目標にすると統一感が出る。

### 影のNG
- **ピロー（枕）シェーディング**：輪郭に沿って外側ほど暗くするだけの影。立体感が出ずボヤける。必ず光源を決めて片側に影を寄せる。
- **バンディング**：明暗の帯が平行に同じ幅で並ぶ。段の位置をずらす、帯幅を変える。
- **ノイズ**：意味のない単独ピクセル。1pxの点は「ハイライト」「瞳孔」など意図があるときだけ使う。

### アンチエイリアス（AA）
- 輪郭の段差の角に、輪郭色と内部色の中間色を1px置くと滑らかに見える。
- 小さいサイズ（〜32px）ではAAを控えめに。外周（シルエットの外側）にはAAを入れない（背景色が変わると汚れる）。

### 輪郭線
- 黒一色ではなく **素材ごとの最暗色** で描く（髪は焦げ茶、肌は赤茶）＝色トレス。アニメの「色トレス線」と同じ考え。
- 光が当たる側の輪郭を1段明るくする（セル・アウト／セレクティブアウトライン）と柔らかく、現代的になる。
- シルエット外周は一番濃く、内部の境界（服と服の重なり等）は一段薄くすると読みやすい。

## 0-3. サイズ別にできること

| キャンバス（全身高さ） | 頭の高さ | 目の大きさ | 表現できること |
|---|---|---|---|
| 16px | 6〜8px | 1×1〜1×2 | 色の塊、シルエットのみ。2〜3頭身 |
| 32px | 10〜14px | 1×2〜2×3 | 目の色、髪型の区別。2.5〜3頭身 |
| 64px | 14〜20px | 3×4前後 | ハイライト1点、服の柄、簡単な影。3〜4頭身 |
| 96〜128px | 20〜26px | 4×5〜6×7 | 虹彩のグラデ、まつげ、1影＋2影、皺。4.5〜6頭身 |
| 150〜200px | 26〜36px | 6×8〜9×11 | 複数ハイライト、まつげの毛束、髪束、生地の質感。5〜7頭身 |

**原則：小さいほど頭を大きく、目を大きく、ディテールを減らす。** ドット絵は「情報を引く」技術。

## 0-4. 作業手順（AIが毎回たどる手順）

1. **仕様を書く**：キャラの年齢感・性格・髪型・髪色・目の色・服・小物・ポーズ・キャンバスサイズ・頭身
2. **パレットを決める**：素材ごとにランプ（3〜5色）、hex で列挙
3. **ランドマーク表**：主要部位のy座標と幅（07の表をサイズに合わせて縮尺）
4. **シルエット**：単色で全体を塗り、シルエットだけでポーズと髪型が読めるか確認
5. **ベタ塗り** → **影** → **輪郭** → **顔ディテール** → **ハイライト** → **クリーンアップ**
6. **レンダリングして確認**（等倍・拡大）、セルフチェック表を順に確認し、問題箇所を座標で特定して直す
7. 必要ならアニメーション（まばたき・呼吸・髪揺れ）をフレーム差分で作る

## 0-5. セルフチェック表

- [ ] シルエットだけで「誰か」「何をしているか」が分かる
- [ ] 頭身・各部位の比率がランドマーク表どおり（01・07）
- [ ] 目の位置が頭の縦の中心より下にある（アニメ顔の基本）
- [ ] 左右の目の高さ・大きさが揃っている（意図的な表情以外）
- [ ] 光源が1方向に統一されている（全パーツの影が同じ側）
- [ ] 落ち影がある：前髪→額、顎→首、腕→胴、スカート→脚
- [ ] 輪郭にダブル・ガタつきがない
- [ ] 孤立ピクセル（意図しない1px）がない
- [ ] パレットが素材ごとにまとまり、総色数が多すぎない
- [ ] 等倍で見て顔が「可愛い」と読める（目・口・頬の情報が潰れていない）
- [ ] 服の皺は引っ張り点（肩・肘・腰・膝）から出ている（02）
- [ ] 色の主役（アクセントカラー）が1〜2色に絞られている（06）

## 0-6. アニメーションの最小セット

| 種類 | フレーム | 内容 |
|---|---|---|
| まばたき | 開き(長) → 半目(1〜2f) → 閉じ(1〜2f) → 半目 → 開き | 開いている時間を2〜4秒取り、たまに2連続まばたき |
| 呼吸（アイドル） | 2〜4f | 頭と胴を1px上下、肩を1px上下。足は動かさない |
| 髪揺れ | 3〜4f | 毛先だけ1px左右。頭の動きより1f遅らせる（追従・フォロースルー） |

フレーム時間の目安: 1f = 80〜150ms。まばたきは閉じ 60〜100ms。

## 0-7. 実際に描いて分かった落とし穴（制作例 character/ のセルフレビューより）

| 落とし穴 | 対策 |
|---|---|
| 片目をスタンプごと左右反転すると **寄り目** になる | まぶた・白目の形だけ反転し、瞳・ハイライトの位置は光源側で両目共通にする |
| ハイライトの白を白目の隣に置くと、白目とつながって消える | ハイライトは虹彩の内側に1px以上離して置く。小ハイライトは白ではなく淡い色に |
| 1px の点を飛び飛びに置いた髪のツヤは「フケ」に見える | 2px 幅以上の帯にして、束の境目でだけ途切れさせる |
| 首まわりの後ろ髪を広く濃い影にすると「ひげ」に見える | 濃い影（2影）は首に接する狭い範囲だけ。横髪で頬の外側を覆うと顔も細く見える |
| 等身大の比率で描くと顔が小さく情報が潰れる | 頭を 1.05〜1.15 倍、目を縦長にする。サイズ別表（0-3）の目の大きさを下限に |
| 座標だけ見て完成とすると必ず破綻が残る | 必ず拡大PNGを見る。顔は ×10 以上に拡大した切り抜きで確認する |
