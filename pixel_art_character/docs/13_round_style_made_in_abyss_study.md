# 13. 「丸で組み立てる」可愛い絵柄の研究 ―『メイドインアビス』の顔と体の比率から

v6 は「惜しい」という評価でした。参考として挙げられた『メイドインアビス』（原作：つくしあきひと、TV アニメのキャラクターデザイン：黄瀬和哉、第2期：黒田結花）の絵柄を研究し、**顔と体の比率・形の作り方** を取り出して v7 に反映しました。

> 注意：特定のキャラクターのデザイン（髪型・服・配色など）は真似していません。取り出したのは「形の作り方と比率の原理」だけです。数値は公開資料に無いため、絵柄の観察から見積もった目安です。

## 13-1. 調べて分かったこと

| 観点 | 内容 | 出典 |
|---|---|---|
| 形の作り方 | キャラクターは **主に円や丸い形で組み立てられ、硬い形を避けている** | 海外の絵柄分析（Medium） |
| 体 | 子どもの体は **「ぷにっとした（blobby）」丸い体**。写実的なデザインから離れている | 海外のアニメ評論（Ink and Image） |
| 頭身 | 劇場版について、キャラクターデザインが **3〜4頭身ほどと極端に低い** という評価 | 日本語版 Wikipedia に引用された評 |

## 13-2. 観察から取り出した比率と形の原理

### 頭と顔
1. **頭は大きく丸い**。頭の幅 ≒ 頭の高さ。輪郭はほぼ円で、顎はほとんど尖らない。
2. **顔の下半分が小さい**。頬は大きく丸く、顎は小さく幅広い丸。
3. **額が広い**（前髪を短くする・分けるなどで額が見える）。
4. **目は低く、離れている**。目の中心は頭頂から 0.6〜0.65、両目の間は片目の幅以上。
5. **目は丸く単純**：大きな丸い瞳、ハイライトは大1＋小1、まつ毛はほとんど描かない、上まぶたの線は細く一定、下まぶたは短い線。2020年代風の情報量の多い目とは逆の方向。
6. **鼻はほとんど描かない**（あってもごく淡い点）。
7. **口はとても小さく、目に近い**。目と口の三角形は非常に低い。
8. 頬の赤みは丸く。

### 体
1. **筋肉の起伏は描かない**。丸い円柱をなめらかにつないだ柔らかい体（smooth min の幅を大きく）。
2. **小柄**：子どもは 3〜4 頭身、肩は狭くなで肩、首は細い。
3. **手足は小さく丸い**（手はミトンに近い形）。
4. 線は細く、陰影は控えめ。情報量は背景に回し、キャラは単純に。

### 年上のキャラクターに応用するとき
子どもの比率（3〜4 頭身）をそのまま使うと幼くなりすぎるため、**顔の作り方（丸い頭・低く離れた目・小さな口）はそのまま、体だけ 4.3〜4.8 頭身** にとどめる。

## 13-3. v6 と v7 の比較

| 項目 | 観察からの目安 | v6 | **v7** |
|---|---|---|---|
| 頭身 | 4.3〜4.8（年上のキャラに応用） | 4.75 | **4.45** |
| 顔の形 | ほぼ円、顎は尖らない、頬が大きい | 頬ふっくら・顎は小さく丸い | **頭蓋を横に広く、頬を大きく、顎を幅広い丸に** |
| 目の中心（頭頂から） | 0.6〜0.65 | 0.62 | **0.65** |
| 両目の間 ÷ 目の幅 | 1.0 以上（離れ気味） | 0.93 | **1.44** |
| 目の形 | 丸く単純、まつ毛ほぼ無し | 2020年代風（差し色・ふち・涙袋・まつ毛の毛束） | **7×7 の丸い目、ハイライト大1＋小1、まつ毛は目尻に1本** |
| 目の幅 ÷ 顔の幅 | — | 0.30 | 0.26（大きくしすぎない） |
| 鼻 | ほぼ無し | 1px の影 | **ごく淡い 1px** |
| 口 | とても小さく目に近い | 4px の ∪ | **3px** |
| 目と口の三角形（高さ ÷ 両目の間隔） | とても低い | 0.43 | **0.30** |
| 額 | 広い | 前髪で隠れる | **前髪を短くして額を見せる** |
| 横髪 | 丸い頬を隠さない | 頬に重なる | **外へずらして頬の輪郭を見せる** |
| 体の筋肉 | 起伏なし | k=3.0 | **k=4.0（より丸く柔らかい）** |
| 体の大きさ | 小柄・なで肩 | 首から下 0.94 倍 | **0.88 倍** |
| 肩幅 ÷ 顔の幅 | 狭い | 1.29 | 1.18 |
| 手・足 | 小さく丸い | 0.34 H / 0.59 H | 0.31 H / 0.54 H |

（顔の幅は「目の高さでの顔の幅」で計測を統一したため、docs/12 の v6 の値と少し違う。）

## 13-4. 学んだこと（これまでの資料との関係）

- docs/11 の「2020年代の目」は情報量を増やす方向、この資料の「丸で組み立てる絵柄」は **情報を減らして形の可愛さで見せる** 方向。どちらも有効だが、**顔と体の情報量をそろえる** こと（docs/11 11-1）が大事。v7 では体を丸く柔らかくしたので、目も単純な丸い目にそろえた。
- 可愛さは「目を大きくする」より、**頭と顔の丸さ・目の位置（低く離れる）・顔の下半分の小ささ・口の小ささ** で出す方が自然（docs/12 の結論とも一致）。
