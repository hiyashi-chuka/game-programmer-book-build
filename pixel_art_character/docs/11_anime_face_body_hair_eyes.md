## 11-1. アニメ顔で不自然にならない体のパーツの比率

### 原則：デフォルメの度合いをそろえる
- 3D キャラクターの知覚研究では、**形と質感のデフォルメ度が食い違う**（例：漫画的な形に写実的な肌）と不気味さが増し、好感が下がると報告されています。絵でも同じで、**顔のデフォルメ度に体を合わせる** のが基本です。
- アニメ顔に合わせる体の作り方：
  1. 筋肉の境目は描かず、なめらかな大きなカーブにする（docs/10 の「アニメ度」k≈3）
  2. **骨の目印（鎖骨・膝・くるぶし・手首）だけ残す**：構造は感じさせつつ、情報量は顔と同程度に
  3. 手足は長くすらっと、関節は小さく
  4. ただし **手と足を小さくしすぎない**（小さすぎる手は初心者が陥りやすい失敗とされる）

### 比率の目安（5〜6頭身の可愛い系女性。H＝頭の高さ、顔の幅＝目の高さでの顔の幅）
| 部位 | 目安 | v4 | v5 | メモ |
|---|---|---|---|---|
| 頭身 | 5〜6 | 5.1 | 5.2 | 小さいドット絵では顔が読める大きさを優先 |
| 首の長さ（顎〜頸窩） | 0.25〜0.35 H | 約0.17 | **0.28** | 短いと頭が肩に埋まって幼く・重く見える |
| 首の幅 | 顔の幅の 0.33〜0.4 | 0.34 | 0.33 | 太いと男性的、細すぎると頭が浮く |
| 肩幅（三角筋の外側） | 顔の幅の 1.4〜1.7 | 1.51 | 1.47 | 狭いと頭でっかち、広いと大人・男性的 |
| 手の長さ（手首〜指先） | 0.4〜0.45 H（顎〜目の下くらい） | **約0.2**（小さすぎ） | **0.38** | 拳・手のひら・指を作り直した |
| 足の長さ | 0.65〜0.8 H | 0.62 | **0.67** | 実際（約1 H）より小さめ。小さすぎると立てなく見える |
| 指先の位置 | 太ももの中ほど | — | — | 腕の長さの基準（docs/09） |
| ウエスト | 肩幅の 0.6〜0.7 | — | — | 服で隠れても中身の形として |
| 手首・足首 | 細く（すねの最大幅の 0.45 前後） | — | — | 関節を細く締めるとアニメらしい |
| 筋肉の起伏 | 境目を見せない | k=3.0 | k=3.0 | 骨の目印だけ残す |

`python3 draw_mio_3d.py` を実行すると、v5 の計測値（上の表の右列）が表示されます。

## 11-2. 顔の輪郭

### 正面
- 頭蓋は **横にやや広い球**。頬は **目の下の高さで一番広く**、そこから顎先へ **なめらかな V〜U** で細くなる。
- **顎の角（えら）は作らない**。顎先は小さく、尖らせすぎない（尖らせると大人っぽく、丸くすると幼くなる）。
- 顔が縦に長すぎると古く見えやすい。
- 後頭部は丸く大きく残す（後頭部が削れると不自然）。

### 3/4 向き
| 部位 | 奥側 | 手前側 |
|---|---|---|
| 輪郭 | 額 → **こめかみで少しへこむ** → **目尻の下に頬骨の小さなふくらみ** → 頬 → 顎先 | 頭の丸みからそのまま顎のラインへ |
| 目 | **幅が狭くなり（60〜75%）、輪郭に近づく** | ほぼそのまま |
| 鼻・口 | 中心線に沿って奥側へずれる。口は奥側が短い | — |
| 顎先 | 顔が向いている方向へ出る | — |

### v5 での作り方（3D）
| 形 | 基本形 |
|---|---|
| 頭蓋 | 楕円体（横 13.7・縦 13.3） |
| 頬 | 目の下を中心にした横長の楕円体（頬が一番広い所） |
| 顎のライン | 頬の左右から顎先へ向かう円錐 2 本（なめらかな V） |
| 顎先 | 小さな楕円体 |
| 頬骨 | 目尻の下に小さな楕円体（3/4 向きで奥の輪郭に小さなふくらみ） |

v4 は「頬と顎が1つの大きな楕円体」だったため、顎まで幅が広い丸顔でした。

## 11-4. 髪型

### 構造（どの髪型にも共通）
1. **頭の形を先に決める**：髪は頭蓋の上に乗り、密着しない。頭頂の髪の厚みは頭の高さの 5〜10%。
2. **つむじ（と分け目）を決める**：すべての毛束は、つむじから頭の丸みに沿って流れる。前髪は分け目から放射状に。
3. **3 つのパートで考える**：前髪・横髪・後ろ髪。後ろ髪が一番大きい。
4. **毛束（クランプ）で作る**：1本1本の線で埋めると平らでごちゃごちゃに見える。太めの束をまとめる。
5. **大・中・小のリズム**：束の太さと長さを規則的にしない。前髪は中央の束を一番大きくし、間に細い束を挟む。
6. **束の分かれ目は下の方だけ**：分かれ目（肌が見える隙間）は生え際より上に入れない。上はなめらか、毛先で分かれる。
7. **ボリュームは控えめに**：髪のボリュームが多すぎると一昔前の絵柄に見えやすい。
8. 毛先は細く尖らせ、少し内側（前髪）や外側（外ハネ）へ向ける。

### 前髪・横髪・後ろ髪の作り方
| パート | ポイント |
|---|---|
| 前髪 | 分け目から放射状。中央が長い。毛先は少し中央へ向ける。束の間から額が見える（シースルーバング）。目元は前髪越しに透かして描く |
| 横髪 | こめかみから頬に沿って S 字に下り、毛先で外へ。後ろにもう1本細い束を重ねて厚みを出す。横髪は前髪より長く鋭い |
| 後ろ髪 | 一番大きいかたまり。上は頭の形をなぞり、下で束に分かれる。内側（首側）は暗く、インナーカラーはここに |

### 可愛い系女性の主な髪型
| 髪型 | 特徴 | 作るときのポイント |
|---|---|---|
| 外ハネボブ（v5） | 顎〜肩の長さ、裾がくびれて外へ跳ねる | 上はふんわり、裾は肩の上で外へ。毛量が少ない方が作りやすい |
| 内巻きボブ | 裾が内側へ丸まる | 毛先を首の方へ曲げる |
| ロング | 背中まで | 肩で一度広がり、背中で束が分かれる |
| ツインテール・ハーフアップ | 結び目から束が出る | 結び目がもう1つの「つむじ」になる |
| ウルフ | トップに段、襟足が長い | 束を尖らせる |
| 姫カット | 顔の横の髪を頬の高さで切りそろえる | 横髪を水平に切る |

### v5 での作り方（3D）
- 土台：頭蓋より少し大きい頭のふくらみ＋ボブのかたまり。
- 後ろ〜横の毛束 13 本：**つむじ（頭頂の後ろ寄り、少し右）から頭の丸みに沿った曲線**（曲線上の点を通る円錐の連なり）。上の方は土台に沈めて表面をなめらかにし、**下の方だけ束が分かれて** 肩の上で外へ跳ねる。太さは「大・中・小」、毛先の高さも1本ずつ変える。
- 前髪 8 本：**分け目から放射状**。中央が最も長く太い、間に細い束。毛先は少し内向き。
- 横髪：S 字の束＋後ろに細い束。
- 輪郭線は深さが大きく飛ぶ所だけ（束が手前に重なる所）にして、線の量を減らした。
- v4 は「中心から等間隔に放射状にのびた同じ太さの円錐」で、櫛のように規則的だった。

## 11-5. 目

目はキャラクターの印象と「絵柄の新しさ」を最も強く決めるパーツです。

### (1) 目の構造（写実の知識をデフォルメの土台に）
| 部位 | 構造 | アニメ・ドットでの表現 |
|---|---|---|
| 眼球 | 球。まぶたはその球に巻きつく | 白目の両端は暗く、中央は明るい（球の陰影） |
| 上まぶた | 厚みがあり、下面は影になる | **まぶたの厚みの影が白目と瞳の上部に落ちる**（瞳の上が暗い理由） |
| 二重のライン | 上まぶたの上のしわ。目の周りで最も硬い影 | 細く短い線を目尻寄りに |
| 瞳（虹彩） | 上まぶたに上部が少し隠れる | 瞳の上端はまぶたの線に接する |
| 瞳孔 | 虹彩の中心 | 若いキャラは大きく、大人っぽいキャラは小さく |
| 下まぶた | 上面に光が当たる。ほとんど動かない | 線は目尻側だけ、下に涙袋のハイライト |
| 目頭 | 涙丘（ピンクの粘膜） | 目頭・目尻に赤みのある色を1px |

### (2) 目の形とキャラクター
| 形 | 判定 | 印象 |
|---|---|---|
| たれ目（v5） | 目尻が瞳の中心より下 | おっとり、優しい |
| つり目 | 目尻が瞳の中心より上 | 気が強い、クール |
| 丸目 | 卵形 | 幼い、元気 |
| 切れ長 | 横に長く縦が狭い（平行四辺形） | 大人っぽい、クール |
| ジト目 | 上まぶたが瞳の上半分を水平に隠す | 呆れ、無気力 |

形だけでなく、**上まぶたの線の角度と瞳孔の大きさ** で性格を調整する。

### (3) 2010年代風と2020年代風の違い
| 項目 | 一昔前に見えやすい | 2020年代に多い |
|---|---|---|
| 目の大きさ・形 | 縦に大きい楕円 | **少し小さく横長**。ただし情報量は増える（2024年夏ごろには目が小さめに戻りつつ細部が増えたとの指摘） |
| 上まぶたの線 | 黒く一定の太さ | **目尻が太く目頭へ細い**。黒でなく暗い赤紫・茶。まつ毛は **2〜3本の毛束** |
| まつ毛の描き込み | — | **まつ毛の上に白（明るい色）の描き込み**（白抜き） |
| 瞳の上部 | 単に暗い | **瞳の上部に虹彩と違う系統の色**（例：紫の瞳に青紫）を入れて深みを出す |
| 虹彩 | 2〜3 色のベタ | 上→下のグラデーション＋**虹彩のふち（暗い輪）**＋細い線 |
| ハイライト | **目の半分ほどの大きな白** | **小さな丸（瞳の中央上に「ちょん」）**＋小さな副ハイライトをいくつか（まつ毛や下まぶたにも） |
| 瞳の下部 | 単色 | 扇形の明るい反射光＋**補色の小さなきらめき**（水色・ピンクなど） |
| 目の下 | 下まつ毛を一周 | 下まつ毛は目尻側だけ、**涙袋のハイライト＋サーモンピンクの赤み** |
| 二重 | なし | 細い二重のライン |
| 全体 | 線が太く黒い | **線は細く、色トレス**。装飾は控えめ |

### (4) 瞳の塗りの層（イラストの一般的な手順）
1. **ベース**：中間の明度・彩度の色（後で影も光も足せるように）。
2. **上部の影**：ベースより濃い色を上部に、瞳の丸みに沿って（まぶたの影）。
3. **差し色**：上部に別系統の色を少し（2020年代の特徴）。
4. **瞳孔**：濃い楕円。
5. **虹彩の模様**：ふちの暗い輪、中心から外へ細い線（視力検査の輪のようなイメージ）。
6. **反射光**：下部にベースより明るい色を **扇形（半円）** に。
7. **発光**：加算・覆い焼きで下部や瞳全体を少し明るく、補色の点を散らす（やりすぎ注意）。
8. **ハイライト**：光源側の上に小さな白、反対側の下に小さな副ハイライト。
9. **まつ毛**：毛束を足し、白の描き込みを入れる。白目の影は髪の色を少し映すとなじむ。

### (5) ドット絵の目のテンプレート（v5、8×8＋二重・下まつ毛・涙袋）
列0 が目尻（外側）、列7 が目頭。右目はまぶた・まつ毛の形だけ左右反転し、瞳とハイライトは反転しない（寄り目を防ぐ）。
```text
..cccc..   c  二重のライン（細く、目尻寄り）
k.KKKKk.   k  まつ毛の毛束（目尻に1本はね）  K 上まぶたのライン（暗い赤紫）
KKKqkkkK   q  まつ毛の上の白抜き。目尻が太く、目頭へ細くなる
KwUUUUdw   目尻が1px下がる（たれ目）。w＝まぶたの厚みの影、U＝瞳の上部の差し色（青紫）
.wdLPPdW   d＝虹彩のふち、L＝小さなハイライト（1px）、P＝瞳孔（2×2、若い＝大きめ）
.WdIPPdW   I＝虹彩
.WdIIIdW
.WdJJxIp   J＝下部の明るいピンク、x＝補色のきらめき（水色）、p＝目頭の赤み
..JGGJ..   G＝扇形の照り返し
.bb.....   b＝下まつ毛（目尻側だけ）
..tttt..   t＝涙袋のハイライト（この下にサーモンピンクの頬の赤み）
```
半目・閉じ目は `eye_modern_template_x24.png` を参照。閉じ目はまつ毛の線を下に弧を描くように。

### (6) サイズ別の目の作り方
| 目のサイズ | できること |
|---|---|
| 1px | 色だけ。個性は髪・服の色で出す |
| 3×3 | 上の行を暗いまぶたの線、中段に白・虹彩・ハイライト、下に任意で下まぶた。**太い上まぶたの線がアニメらしさの要** |
| 5×5 | 上まぶた＋虹彩2色＋ハイライト1px |
| 8×8 以上 | (5) のテンプレート：まつ毛の毛束、差し色、ふち、きらめき、涙袋 |

- 表情は **上まぶたを1px 動かす** だけで変わる（下げると不機嫌・怒り、上げると驚き）。
- **ハイライトが少ないと目が死んで見え、多いと可愛く見える**（ただし大きすぎると古く見える）。

### (7) 3/4 向き・横向き
- 3/4：奥の目は幅を狭く（v5 は白目の列を1つ減らす）、輪郭に近づける。手前の目はほぼそのまま。
- 横向き：目は「く」の字の三角形、瞳は縦長の楕円の半分。まつ毛は外へ突き出す。
- 両目の瞳孔は同じ方向へずらす（視線）。v5 は顔がカメラから少しそれているので、瞳孔をカメラ側へ寄せている。

### (8) 前髪と目
- まつ毛が前髪に隠れると眠そうに見える。アニメでは **前髪の上に目元を透かして描く** ことが多い（v5 も目のスタンプを前髪の上に描く）。
