# 10. 骨格・筋肉を3次元で捉えて描く方法と、それをアニメ調で描く方法

これまでの資料（01・09）は、体を「正面から見た輪郭の太さ」として扱っていました。この資料では、

1. 骨格と筋肉を **立体（前後・左右・上下の厚みを持つかたまり）** として捉える知識
2. その立体を **アニメっぽく見せる** 知識（アニメ調 3DCG＝セルルックの技法）
3. AI が画像生成なしで、**3D の人体モデルを作ってドット絵にする** 手順

をまとめ、制作例 v4（`character/draw_mio_3d.py`）で実際に描きました。

- `character/output/mio3d_anatomy_x4.png`：服を外し、骨の目印と筋肉を色分けした 3D モデル（正面・斜め・横）
- `character/output/mio3d_smooth_compare.png`：筋肉のつなぎ方の幅（写実〜アニメ）の比較

## 10-0. これまでの知識が浅かった理由

| v1〜v3 の方法 | 問題 |
|---|---|
| 正面から見た輪郭の「太さの表」で肉付け | 前後の厚み（太ももの前の大腿四頭筋と後ろのハムストリングスなど）が無く、向きを変えると描けない |
| 骨の目印（膝蓋骨・くるぶし等）を持たない | 関節が「くびれた筒」になり、膝や肘がそれらしく見えない |
| 影は 2D のマスクから推定 | 腕が胴に落とす影、前髪が額に落とす影などが形に正確に沿わない |
| 3/4 向きや横向きに対応できない | 奥行きのある構図が作れない |
| **ふくらはぎの高さを逆に覚えていた** | 正しくは「外側のふくらみが高く、内側のふくらみが低い」。01・09 を訂正した |

## 10-1. 体を立体で捉える考え方

### 4つの層で組み立てる
| 層 | 内容 | 見た目への影響 |
|---|---|---|
| 1. 骨格 | 関節の位置と骨の長さ | ポーズ・比率・重心（09） |
| 2. 骨の目印 | 皮膚のすぐ下にある骨（鎖骨、膝蓋骨、くるぶし…） | 肉の量が変わっても位置が変わらない「固定点」。関節がそれらしく見える |
| 3. 筋肉のかたまり | 骨につく筋肉のふくらみ | 輪郭の起伏のリズム、前後の厚み |
| 4. 脂肪と皮膚 | 全体をなめらかに包む | 女性・アニメでは厚めに考え、筋肉の境目をなめらかにする |

### 立体の捉え方の基本
- **箱と円柱で考える**：胸郭（卵形の箱）、骨盤（箱）、手足（円柱）。それぞれに「前・横・後ろ」の面がある。
- **断面を考える**：太ももの断面は前後より左右がやや広い楕円、すねの断面は前が尖った三角形（脛骨の前縁）、首の断面は前に胸鎖乳突筋が出た台形。
- **形は重なり合う**：筋肉は手前の形が奥の形に重なる（くさび状に入り込む）。輪郭は1本の線でなく、重なった形の連続。
- **リズム（高い・低い）**：手足の輪郭のふくらみは左右で高さがずれ、交互に続く（10-3）。

## 10-2. 骨の目印（皮膚のすぐ下にある骨）

| 部位 | 骨の目印 | 立体での位置 | アニメ（女性）での扱い |
|---|---|---|---|
| 首の付け根 | 頸窩（胸骨上端のくぼみ） | 左右の鎖骨の内端の間 | 小さなくぼみの影、ネックレスの位置 |
| 肩 | 鎖骨 | 頸窩から肩先へ、前に弓なりの浅い S 字。肩先は後ろへ下がる | **必ず描く**。細い線か 1〜2px の影 |
| 肩 | 肩峰（肩甲骨の端） | 鎖骨の外端。肩の一番上の角 | 肩の丸みの頂点として |
| 背中 | 第7頸椎、肩甲棘、肩甲骨の内側縁 | 首の付け根の後ろの突起 | 後ろ姿で軽く |
| 胴 | 肋骨の下縁、胸骨 | みぞおちから左右に開く逆 V | ほぼ描かない |
| 腰 | 腸骨稜・上前腸骨棘 | 骨盤の上縁。前の角がウエストの下 | 水着・ローライズのときだけ |
| 腰の横 | 大転子 | 股関節の外側、腰の一番広い所 | 腰幅として輪郭に |
| 肘 | 肘頭、内側・外側上顆 | 肘の後ろの突起と左右の出っ張り | 曲げた肘の角として |
| 手首 | 尺骨の頭 | 手首の小指側の出っ張り | 1px の影 |
| 膝 | 膝蓋骨、大腿骨の顆、脛骨粗面 | 膝の前の丸い板とその下の突起 | 膝の位置を示す短い線・影。**強調しすぎない** |
| すね | 脛骨の前縁 | 膝からくるぶしまで、すねの前に一直線 | 脚の前側の輪郭がまっすぐな理由 |
| 足首 | 内くるぶし・外くるぶし | **内側が高く、外側が低い** | 足首の左右の段差 |

## 10-3. 筋肉（部位別）

位置は「骨に沿った割合 t（付け根 0〜先端 1）」「外側への距離 s」「前への距離 f」で書いた（制作例 v4 の値。H=28.7px の体）。

### 首・肩
| 筋肉 | 付き方 | 表面の形 | アニメでの扱い |
|---|---|---|---|
| 胸鎖乳突筋 | 耳の後ろ → 鎖骨の内端・胸骨 | 首の前に斜めの2本の柱。V 字に頸窩へ集まる | 首を回したときだけ1本、または描かない |
| 僧帽筋 | 後頭部・首 → 鎖骨の外側・肩甲骨 | 首から肩へのなだらかな斜面 | 女性はなで肩として斜面だけ |
| 三角筋 | 鎖骨・肩峰・肩甲棘 → 上腕の外側 | 肩の丸いキャップ | 肩の丸みとして |

### 腕
| 筋肉 | 位置（v4） | 表面の形 |
|---|---|---|
| 上腕二頭筋 | 上腕の前 t=0.56 | 前のふくらみ。腕を曲げると短く盛り上がる |
| 上腕三頭筋 | 上腕の後ろ t=0.45 | 後ろの長いふくらみ（二の腕） |
| 上腕筋 | 上腕の外側 t=0.72 | 肘の上の外側のふくらみ |
| 腕橈骨筋 | 前腕の外側（親指側）t=0.25 | **肘のすぐ下の外側のふくらみ**。前腕が肘側で太く手首へ細くなる理由 |
| 屈筋群・伸筋群 | 前腕の内側・後ろ t=0.3 | 前腕の厚み |

### 胴
| 筋肉 | 表面の形 | アニメ（女性）での扱い |
|---|---|---|
| 大胸筋 | 胸の上部、脇へつながる | 胸のふくらみの付け根として |
| 前鋸筋・腹斜筋 | 脇腹 | くびれの輪郭 |
| 腹直筋 | お腹の縦の帯 | へその縦線1本程度 |
| 大殿筋 | お尻 | 後ろ・横の丸み |

### 太もも
| 筋肉 | 位置（v4） | 表面の形 |
|---|---|---|
| 大腿直筋 | 前 t=0.45, f=+2.1 | 前の中央の長いふくらみ |
| 外側広筋 | 外側 t=0.50, s=+2.6 | **外側の長いふくらみ（太ももの外側は高い位置から長くふくらむ）** |
| 内側広筋 | 内側 t=0.80, s=−2.3 | **膝のすぐ上の内側の涙形のふくらみ（内側は低い位置）** |
| 内転筋群 | 内側上部 t=0.25 | 内ももの上部の厚み |
| ハムストリングス | 後ろ t=0.50 | 横から見た太ももの後ろの丸み |
| 大転子 | 外側 t≈0 | 腰の横の出っ張り |

### すね・ふくらはぎ
| 筋肉 | 位置（v4） | 表面の形 |
|---|---|---|
| 腓腹筋・外側頭 | 外側 t=0.26（高い）| ふくらはぎの外側のふくらみは **高い位置で小さい** |
| 腓腹筋・内側頭 | 内側 t=0.36（低い）| ふくらはぎの内側のふくらみは **低い位置まで下がり、大きい** |
| ヒラメ筋 | 後ろ t=0.55 | ふくらはぎの下半分の厚み |
| 前脛骨筋 | 前外側 t=0.35 | すねの外側の細いふくらみ |
| アキレス腱 | 後ろ t=0.72〜1.0 | かかとへ細く締まる |

### 脚の輪郭のリズム（正面）
```text
外側         内側
 ╲  高い      太もも：外側は腰（大転子）から長くふくらむ
  │          
  │   ╱ 低い  膝の上の内側に内側広筋の涙形
  │  │       
 ╱ 高い │     ふくらはぎ：外側が高い
 │    ╲ 低い  ふくらはぎ：内側が低く大きい
 │    │      
 ╲低い ╱高い  足首：外くるぶしが低く、内くるぶしが高い（ここだけ逆）
```

## 10-4. 女性・アニメキャラでの扱い

- **脂肪の層が厚い** → 筋肉の境目は見えず、なめらかな大きなカーブになる。ただし **骨の目印（鎖骨・膝・くるぶし・手首）は残す** と、細くても構造がある体に見える。
- 筋肉の知識は「描くため」ではなく **輪郭のカーブの位置と、陰影の形を正しくするため** に使う。v4 の脚は筋肉ごとに形を作ったうえで、つなぎ目をなめらかにしてある。
- アニメで描く骨・筋肉の目安（可愛い系の女性）：
  | 描く | 控えめに | 描かない |
  |---|---|---|
  | 鎖骨、頸窩、膝の位置、くるぶし、手首の骨、肘の角 | 胸鎖乳突筋（首を回した時）、膝蓋骨の下の影、へその線 | 腹筋の割れ、肋骨、腕・脚の筋肉の境目 |

## 10-5. アニメ調 3D（セルルック）の技法

アニメ調の 3D キャラクター（格闘ゲーム、ソーシャルゲーム、VTuber、アニメの 3DCG パート）は、**3D の正確な立体を使いながら、手描きのアニメに見せるための工夫** を重ねています。調べた主な技法：

| 技法 | 内容 | v4 での実装 |
|---|---|---|
| セルシェーディング（トゥーンシェーダー） | 光の当たり具合を数段階のベタ色に分ける。境目はぼかさない | 光との内積を 5 段階（hi/lt/base/s1/s2）に量子化 |
| **法線の編集（法線転写）** | 顔は細かい凹凸のせいで汚い影が出るため、**球の法線を顔に転写** して影の形を単純化する（顎の下・外側だけに影） | 顔のピクセルだけ、頭を包む楕円体の法線を使い、さらに正面寄りに倒す |
| 顔の影のマップ（SDF 顔影） | 光の角度ごとに顔のどこまで影にするかを白黒のテクスチャで指定する方法（ソーシャルゲームで多い） | 未実装（ドット絵の解像度では法線転写で十分） |
| 固定影と光による影の併用 | 首の下など常に影にしたい所は固定で塗り、残りを光で決める | 落ち影は光線で判定、首の下は顎が影を落とすので自然に入る |
| 輪郭線（背面法・インバーテッドハル） | 少しふくらませたモデルの裏面を黒く描いて輪郭にする。太さは頂点ごとに調整 | ピクセルの深度とパーツ ID の差から 1px の線を引く（画像処理での輪郭抽出） |
| 輪郭線の太さの調整 | 口の中などは線を消す、毛先は細くする | 明部は明るい線、影は濃い線（線の強弱） |
| 髪は束（クランプ）で作る | 1本1本ではなく、先の尖った束を重ねて作る。束ごとに影が出る | 毛先の細い円錐を約45個、頭のふくらみとなめらかにつなぐ |
| 髪のハイライト | 鏡面反射の帯（天使の輪）。テクスチャで描くことも多い | 光と視線の中間方向との内積で帯を作る。束の溝で自然に途切れる |
| 目は平らな板に描く | アニメの目は立体の眼球ではなく、ほぼ平らな面にテクスチャで描く（大きなハイライトが立体の眼球では不自然になるため） | 目・口は 3D の位置を画面に投影し、ドットのスタンプで描く |
| 3D をドット絵にする | 3D モデルを低解像度で、アンチエイリアスなしにセル塗りで描画してドット絵の素材にする（『Dead Cells』のキャラクターの作り方） | 96×176 の各ピクセルの中心で 1 本ずつ光線を飛ばし、ぼかさずに描画 |
| デフォルメの調整 | 3D でも頭身・目の大きさ・手足の細さはアニメの比率で作る。写実的な質感にしない | 筋肉のつなぎ方の幅（smooth min の k）で写実〜アニメを調整（下表） |

### 筋肉のつなぎ方の幅＝「アニメ度」（`mio3d_smooth_compare.png`）
| k | 見え方 |
|---|---|
| 1.2 | 筋肉ごとの起伏が残る（写実・筋肉質） |
| 3.0 | 膝・ふくらはぎの位置は分かるが境目はなめらか（**アニメの女性キャラ向け**、v4 の値） |
| 4.5 | ほぼ円柱（デフォルメ強め・ちびキャラ寄り） |

## 10-6. AI が 3D モデルを作ってドット絵にする手順（v4 の方法）

ポリゴンのモデルを作る代わりに、**符号付き距離関数（SDF）** で形を表します。「点が形の表面からどれだけ離れているか」を返す関数で、楕円体・円錐・角の丸い箱などを組み合わせるだけで体を作れるため、コードだけで人体を組み立てるのに向いています。

1. **骨格**：関節の位置を比率表とポーズで決める。腕と脚は **2 ボーン IK**（付け根と先端の位置から、骨の長さを保って肘・膝の位置を計算）で、骨の長さを厳密に守る。
2. **骨の目印と筋肉**：骨ごとに座標系（骨の向き・外側・前）を作り、10-2・10-3 の位置に楕円体と円錐を置く。
3. **なめらかに合成**：smooth min（2 つの形を幅 k でなめらかにつなぐ最小値）で筋肉と骨を合成する。k が大きいほどアニメ調。
4. **服**：体の形を少しふくらませた殻（Tシャツは +0.7、カーディガンは +2.3 で前を切り開く）、スカートは楕円錐の半径をのこぎり波で変えてプリーツを作る、ソックスはすねをふくらませて上端を切る。
5. **髪**：頭のふくらみ＋ボブの楕円体＋毛束の円錐。顎より下の髪は頭の傾きを戻して真下に垂らす（重力）。
6. **描画（レイ・マーチング）**：各ピクセルから光線を飛ばし、距離関数の値だけ進むことを繰り返して表面に当たる点を探す。当たった点の **深度・法線・パーツ ID** を記録する。
7. **セル塗り**：光の向きと法線の内積を段階に分ける。影の判定は表面から光の方へもう一度光線を飛ばし、当たれば影（落ち影が形に正確に沿う）。周囲の距離から凹み（オクルージョン）を求めて1段暗くする。
8. **アニメの工夫**：顔は球の法線、髪は鏡面反射の帯、影側の縁にリムライト、深度と ID の差で輪郭線。
9. **顔のパーツ**：目・眉・口・頬の 3D 位置を画面に投影し、ドットのスタンプで描く。奥の目は1列狭くする（3/4 向き）。
10. **確認**：服を外して筋肉を色分けした解剖モデルを、正面・斜め・横の 3 方向から描画して形を検証する（`mio3d_anatomy_x4.png`）。

### 2D の方法（v1〜v3）との使い分け
| | 2D（図形を直接描く） | 3D（モデルを作って描画） |
|---|---|---|
| 向きの変更 | 描き直しが必要 | 角度を変えるだけ（正面・斜め・横） |
| 陰影・落ち影 | 推定（ずれやすい） | 形に正確に沿う |
| 解剖学的な正しさ | 輪郭の太さの表のみ | 骨の目印・筋肉の位置・前後の厚みまで |
| 顔の可愛さ | 調整しやすい | 法線転写・スタンプなどの工夫が必要 |
| 計算時間 | 約1秒 | 1枚あたり約6秒 |

## 10-7. チェックリスト

- [ ] 骨の長さは IK で守られている（肘・膝が伸びすぎていない）
- [ ] 鎖骨・頸窩・膝・くるぶし・手首の骨の目印がある
- [ ] 太ももの外側は長くふくらみ、膝の上の内側に内側広筋の涙形がある
- [ ] ふくらはぎは外側が高く、内側が低く大きい
- [ ] 内くるぶしが高く、外くるぶしが低い
- [ ] すねの前（脛骨）はまっすぐ
- [ ] 前腕は肘側（腕橈骨筋）が太く、手首へ細くなる
- [ ] 横から見ても形が成立している（太ももの前後の厚み、ふくらはぎの後ろのふくらみ）
- [ ] 筋肉の境目のなめらかさがキャラの絵柄に合っている（アニメの女性なら k≈3）
- [ ] 顔に汚い影が出ていない（法線転写）
- [ ] 落ち影（前髪→額、顎→首、腕→胴、スカート→脚）が形に沿っている
