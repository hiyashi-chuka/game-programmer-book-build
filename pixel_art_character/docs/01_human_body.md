# 01. 人体の構造 ― 骨格・筋肉・皮膚・髪の毛

絵として必要な「見た目に影響する構造」に絞ってまとめます。単位 **H = 頭の高さ（頭頂〜顎先）** を基準にします。

---

## 1-1. プロポーション（頭身）

| 用途 | 頭身 | 特徴 |
|---|---|---|
| 実在の成人女性 | 7〜7.5 | 股下 ≒ 身長の 45〜47% |
| 一般的なTVアニメの女性 | 6.5〜7.5 | 脚を長めに、頭をやや大きめに |
| 可愛い系・学園もの | 5.5〜6.5 | 頭と目を大きく、首を細く |
| ドット絵の立ち絵（96〜200px） | 4.5〜6 | 表情が読めるよう頭を大きく |
| ちびキャラ | 2〜3 | 胴＝頭以下、手足は棒＋丸 |

### 6頭身（可愛い系アニメ女性）のランドマーク（頭頂=0, 足裏=6H）

| 部位 | 位置（上から） | 幅（正面） |
|---|---|---|
| 頭頂 | 0 | 頭幅 0.75〜0.8H |
| 目 | 0.55〜0.6H | 片目幅 0.2〜0.25H |
| 顎 | 1.0H | — |
| 肩の線 | 1.3H | 肩幅 1.4〜1.6H（女性） |
| バスト頂点 | 1.8〜1.9H | — |
| 肘 / ウエスト（最細部） | 2.3〜2.4H | ウエスト 0.9〜1.0H |
| 腰骨・ヒップ最大幅 | 2.7〜2.9H | ヒップ 1.4〜1.5H（肩幅とほぼ同じ） |
| 股 / 手首 | 3.0H | — |
| 指先 | 3.4〜3.5H | — |
| 膝（膝蓋骨の中心） | 4.3〜4.5H | 膝幅 0.35H |
| 足首 | 5.7〜5.8H | 0.2H |
| 足裏 | 6.0H | 足の長さ ≒ 1H |

要点:
- **肘はウエスト、手首は股** の高さ。腕を下ろした絵で崩れやすいので必ず確認。
- **股は全身のほぼ中央**（アニメでは中央よりやや上にして脚を長く見せる）。
- 手の長さ（手首〜中指先）≒ 顔の長さ（髪の生え際〜顎）の 0.75〜0.8。
- 女性は「肩幅 ≒ ヒップ幅」「ウエストがくびれる」「首が細く長め」「手足の関節が小さい」。

## 1-2. 骨格（形を決める骨）

絵では骨を「箱・球・円柱」に単純化して考えます（マネキン法）。

| 骨 | 単純化 | 見た目への影響 |
|---|---|---|
| 頭蓋骨 | 球＋顎の楔形 | 頭の丸み、顎のライン、こめかみの凹み |
| 脊柱 | S字カーブ | 横から見た背中の反り。首は前傾、腰は前に反る |
| 胸郭（肋骨） | 卵形（上が小さい） | 胴の上半分の形。女性は小さめ |
| 骨盤 | 浅い箱／蝶形 | 女性は幅広く前傾 → ヒップと腰の丸み |
| 鎖骨 | 浅いS字の棒 | 首の付け根の水平ライン。可愛い絵でも1〜2pxで描くと色気と立体感が出る |
| 肩甲骨 | 三角板 | 背面図の肩の凹凸 |
| 上腕骨・前腕（橈骨・尺骨） | 円柱 | 前腕は手首でひねられ、手のひらの向きで太さが変わる |
| 大腿骨 | 斜めの円柱 | **股関節は外、膝は内側** に寄る（Q角）。女性はこの角度が大きく、X脚気味に見える |
| 脛骨 | 円柱 | すねの前は直線的、ふくらはぎ側が丸い |
| 膝蓋骨 | 小さな円 | 膝の位置の目印。ドットでは 1〜2px の影で示す |
| くるぶし | 内側が高く、外側が低い | 足首の非対称。細部で差が出る |

### 関節の可動域（ポーズで破綻しないために）
- 首: 左右回転 ±70°、傾き ±40°
- 肩: 腕は前方 180°、横方向に上げると鎖骨・肩甲骨も一緒に上がる
- 肘・膝: 一方向にしか曲がらない（約145°）
- 手首: 背屈・掌屈 各70°前後
- 腰（体幹）: ねじり ±40°、前屈は股関節が主体

## 1-3. 筋肉（表面に出る形だけ）

アニメの可愛い女性キャラでは筋肉は「ほとんど描かない」。ただし **形の膨らみの位置** を知っていると輪郭のカーブが自然になります。

| 筋肉 | 位置 | 輪郭への影響 | 描く量（可愛い系） |
|---|---|---|---|
| 胸鎖乳突筋 | 耳の下〜鎖骨の中央 | 首の斜めの筋。首をひねると出る | 振り向き時のみ1本線 |
| 僧帽筋 | 首の付け根〜肩 | 首から肩への **なだらかな斜面** | 輪郭の傾きとして表現 |
| 三角筋 | 肩の丸み | 肩先の丸いふくらみ | 輪郭の丸みのみ |
| 上腕二頭筋／三頭筋 | 二の腕 | 腕の前後のふくらみ（女性は控えめ） | 描かない |
| 前腕の筋群 | 肘下 | **肘側が太く手首に向けて細くなる** テーパー | 輪郭のみ |
| 腹斜筋 | 脇腹 | くびれのライン | 輪郭のみ |
| 大臀筋 | お尻 | 後ろ姿・横の丸み | 輪郭のみ |
| 大腿四頭筋 | 太もも前 | 太ももの前側の丸み、膝上で内側に膨らむ | 輪郭のみ |
| 腓腹筋 | ふくらはぎ | **内側が高く膨らみ、外側が低く膨らむ** | 輪郭のみ（脚の美しさの要） |

**脚の輪郭のコツ（正面）**: 太ももの外側はなだらかに膝へ、内側は膝上で一度ふくらむ。ふくらはぎは内側のふくらみが外側より大きく、位置もやや高い。足首は細く締める。

## 1-4. 皮膚（肌）の描き方

### 肌の色ランプ（明るい肌・アニメ調）
| 用途 | hex | メモ |
|---|---|---|
| ハイライト | `#fff3ea` | 頬・鼻先・膝頭・肩先に少量 |
| ベース | `#ffe1cf` | 最も面積が大きい |
| 1影 | `#f5b9a6` | 赤みを足して少し彩度UP（紫寄りの赤） |
| 2影（濃い影） | `#d98f86` | 前髪の真下、首の顎下の最も深い所 |
| 輪郭（色トレス） | `#a8605e` | 黒ではなく赤茶 |
| 頬の赤み | `#ffb3b0`〜`#ff9d9d` | 楕円 or 斜線 |

他の肌色も「影は赤〜紫寄り、明部は黄〜白寄り」へ色相シフトさせる。褐色肌なら ベース `#c98e6a` / 影 `#9c5f4d` / 明 `#e3b08c` など。

### 肌の影が入る場所（光源：左上の場合）
- **前髪の落ち影**：額に前髪の形をなぞった影（前髪の毛先の形を2〜3px下へずらした形）
- **顎の落ち影**：首の上部全体。顎のラインを写した形。可愛い系ではここが一番大事な影
- **鼻**：右側に小さな影（1〜3px）、または鼻先の点だけ
- **耳**：耳の穴・内側
- **鎖骨の下**、**脇**、**胸の下**、**太ももの内側**、**膝の裏**
- 腕・脚の光と反対側に細い縦長の影（円柱の形状影）

### 肌の質感表現
- 若いキャラは **影を少なく、境界をはっきり** させる（セル塗り）。
- 頬の赤み（チーク）は可愛さを最も上げる要素。ドットでは「肌ベースと赤の中間色を2〜4pxの横長楕円」か「斜線3本」。
- 膝・肘・指先・肩先にも薄くチークを入れると血色が良く見える（近年のイラストで多い）。

## 1-5. 髪の毛の描き方

### 構造
1. **頭蓋骨の外側に厚み** をもたせる：髪のシルエットは頭蓋骨より上に 1〜3px（96〜200pxサイズ）大きい。
2. **つむじ** から放射状に流れる。分け目（センター、サイド）を決める。
3. **生え際** は額の上部、耳の前、うなじ。前髪はここから前へ垂れる。
4. 髪は「1本1本」ではなく **束（房）** のまとまりで描く。束は根元が太く、毛先で細く尖る（または丸く）。
5. **前髪 / 横髪（サイドの触覚・もみあげ） / 後ろ髪（内側・外側の2層）** の3レイヤー＋α。

### レイヤーと描画順
| レイヤー | 描画順 | 色 |
|---|---|---|
| 後ろ髪の内側（裏面） | 最奥 | 最も暗い（影2）。インナーカラーを入れるならここ |
| 後ろ髪の外側 | 体の後ろ | ベース＋影 |
| 顔・体 | — | — |
| 横髪（サイドロック） | 顔の手前 | ベース。顔に沿った細い束 |
| 前髪 | 最前 | ベース＋ハイライト |

### 束の形（ドットパターン、縦に垂れる束の毛先）
```text
 尖った毛先            丸い毛先            分かれた毛先
 HHHHHH                HHHHHH              HHHHHHH
 HHHHHH                HHHHHH              HHHhHHH
 .HHHH.                HHHHHH              HHH.HHH
 .HHHH.                .HHHH.              .HH..HH
 ..HH..                ..HH..              .H....H
 ..H...
```

### 髪の影
- **束と束の間** に細いくさび形の影（根元側が太く、毛先方向に細くなる）。
- **前髪の根元付近**（頭頂の丸みの下側）。
- **後ろ髪の内側** は全体的に暗く。顔の両側に見える後ろ髪の裏面は一番暗い。
- 首まわり・肩に落ちる髪の影。

### ハイライト（天使の輪）
- 頭の丸みに沿った **横方向の帯** を、頭頂から 1/3 くらいの高さに入れる。
- 帯は連続させず、**束ごとにジグザグに途切れさせる**（ギザギザの短い横線の連なり）。
- ドット例（髪ベースH、ハイライトL）:
  ```text
  HHHHHHHHHHHHHHH
  HHLLHHHLLLHHLLH
  HLLLLHLLLLLHLLL
  HHHLHHHHLHHHHLH
  HHHHHHHHHHHHHHH
  ```
- 近年のアニメでは、ハイライトを白に近づけすぎず「ベースより1〜2段明るい色」に留め、**前髪の毛先を肌色に透かす**（前髪の先1〜2pxを髪色と肌色の中間色にする）表現も多い。

| ミルクティーベージュ | `#6e4a42` | `#a77866` | `#c99a80` | `#e6c3a5` | `#f4dcc4` | `#fff0e0` |
| ピンクブラウン | `#6a3a44` | `#9c5a62` | `#c27d82` | `#dea2a3` | `#f0c4c2` | `#ffe6e2` |
| 黒髪（青み） | `#16141f` | `#24223a` | `#34324f` | `#4a4868` | `#6e6c94` | `#9a98c0` |

### 髪型のバリエーション（現代風・女性）
- **ボブ／外ハネボブ**：顎〜肩の長さ、毛先を外に跳ねさせると活発・トレンド感
- **ウルフカット**：トップに段（レイヤー）、襟足が長い。束が尖る
- **ロング＋顔周りレイヤー**：顔まわりを短く段にしてシルエットに動き
- **シースルーバング**：前髪の隙間から額が見える。束の間に肌色を 1px 縦に通す
- **インナーカラー**：後ろ髪の内側だけ別色（ピンク・水色・紫など）。動いたときにちらりと見せる
- **ハーフアップ、お団子、ツインテール、編み込み**：束の流れが変わる部分に影を入れる
