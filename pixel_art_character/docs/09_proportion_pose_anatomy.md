## 9-1. 体の比率

### 頭身を変えても崩してはいけない「関係」
頭身（デフォルメの度合い）は作品ごとに変えてよいが、次の **部位どうしの関係** は保つと自然に見えます。

| 関係 | 内容 |
|---|---|
| 股 ≒ 全身の中央 | アニメでは中央よりやや上（0.48〜0.5）にして脚を長く見せる |
| 肘 ＝ ウエスト | 腕を下ろしたとき、肘はウエストのくびれの高さ |
| 手首 ＝ 股 | 手首は股（脚の付け根）の高さ |
| 指先 ＝ 太ももの中ほど | 腕が短いと「手が腰で止まる」ので幼児的に見える |
| 膝 ＝ 「足の甲」と「全身の中央」の中間 | 膝が低すぎると脚が短く、高すぎると太ももが短く見える |
| 肩幅 ≒ 腰幅（女性） | 女性は肩と腰がほぼ同じ幅、男性は肩が広い |
| ウエスト ≒ 肩幅の 0.6〜0.7 | 服で隠れていても、中身の体の形として決めておく |

### 頭身を決める
| 頭身 | 印象 | 頭が大きいときの調整 |
|---|---|---|
| 2〜3 | ちびキャラ | 首はほぼ無し、手足は棒＋丸 |
| 4〜4.5 | 幼い、マスコット的 | 首が短く、腕も短くなりがち。腕の長さの関係は保つ |
| 5〜6 | **可愛い系の立ち絵（ドット絵の標準）** | 頭が大きい分、胴と脚を縮める（下の計算） |
| 6.5〜7.5 | TVアニメの標準〜大人っぽい | 目を小さめに、首を長めに |

**頭を大きくしたときの体の縮め方**：実際の人体（7.5頭身）の顎から下の位置 p（全身に対する割合）を、
`p' = h + (p − 1/7.5) × (1 − h) / (1 − 1/7.5)`（h＝1/頭身）で写すと、関係を保ったまま頭身を変えられます。
例：5.5頭身・全身 154px なら、肩 ≒ 頭頂から 34px、肘・ウエスト ≒ 65px、股 ≒ 77〜78px、膝 ≒ 113px、足首 ≒ 147px。

### 女性の体の特徴（形を決める構造）
- **骨盤が広く浅い** → 太ももの骨（大腿骨）が股関節から膝へ内側に強く傾く（Q角が大きい）。膝が内に寄り、X脚気味。
- **胸郭が小さく、下部が締まる** → ウエストのくびれ。
- **なで肩**：首から肩への斜面（僧帽筋）がなだらか。
- **腕のキャリングアングル**：手のひらを前に向けて腕を下ろすと、前腕が肘で外へ開く。女性は特に目立つ。
- 首は細く長め、関節（手首・足首・膝）は小さい。

## 9-2. 顔の比率（アニメ顔）

### ルーミス法の基準とアニメでの変え方
写実の頭（ルーミス法）は「生え際〜眉」「眉〜鼻」「鼻〜顎」の3等分で、目は頭頂と顎のほぼ中間。アニメはこれを基準に **目を大きく下げ、鼻と口を小さく下に寄せる** 方向に崩します。

| 位置（頭頂=0, 顎=1） | 写実（ルーミス） | アニメ可愛い系 | 制作例 v3 |
|---|---|---|---|
| 生え際 | 0.25 前後 | 0.2〜0.25（前髪で隠れる） | — |
| 眉 | 0.45 前後 | 目の上端のすぐ上（目が大きいほど上がる。0.33〜0.45） | 0.35（前髪越し） |
| 目の中心 | 0.5 | **0.55〜0.62** | 0.57 |
| 鼻 | 0.72 前後 | 0.75〜0.8 | 0.80 |
| 口 | 0.82 前後 | **0.83〜0.88** | 0.87 |
| 顎 | 1.0 | 1.0 | 1.0 |

| 幅 | 目安 |
|---|---|
| 顔の幅（頬） | 0.85〜0.9H |
| 片目の幅 | 顔の幅の 0.27〜0.31 |
| 両目の間 | 片目の幅の 0.8〜1.0 倍 |
| 口の幅 | 顔の幅の 1/6〜1/5 |
| 首の幅 | 顔の幅の 0.33〜0.4（女性・アニメ） |
| 耳 | 眉の高さ〜鼻の高さ（髪で隠れることが多い） |

### 年齢・印象と顔の比率
| 印象 | 目の位置 | 目の大きさ | 顎 | 首 |
|---|---|---|---|---|
| 幼い | 低い（0.62〜） | 大きい・丸い | 短く丸い | 短く細い |
| 10代後半〜20代の可愛い系 | 0.55〜0.6 | 大きめ | やや細い U〜V | 普通（0.25〜0.35H） |
| 大人っぽい | 0.5〜0.55 | 細め・切れ長 | 長めでシャープ | 長い |

**口と顎の距離** は見落としやすい。口が顎に近すぎると（v2 の 0.92）顎が極端に短く見え、顔全体のバランスが崩れる。

## 9-3. ポーズ

### 手順
1. **アクションライン**：頭から支持脚まで、体を通る1本のゆるい C 字・S 字の線を最初に決める。垂直の直線は像のように硬い。
2. **重心と支持脚**：**首の付け根（頸窩）から真下に下ろした線が、体重を支える足の上に落ちる** ようにする。外れると倒れそうに見える。
3. **骨盤の傾き**：支持脚側の骨盤が上がり、腰がその側へ張り出す。
4. **肩の逆傾斜**：肩は骨盤と逆向きに傾く（支持脚側の肩が下がる）。
5. **背骨のカーブ**：骨盤と肩をつなぐように背骨が横に曲がる。支持脚側の脇腹は縮み、反対側は伸びる。
6. **頭**：肩の線と逆向きに少し傾けると、「頭・肩・骨盤」の線がジグザグになり、リズムが生まれる。
7. **遊脚**：体重のかかっていない脚は膝を曲げ、力を抜く。膝を内に寄せ、つま先を内に向けると可愛い（内股）。
8. **腕**：左右で違う動きにする。片方は曲げて体の前へ（重なり＝奥行き）、片方は下ろす。
9. **シルエット確認**：黒く塗りつぶしても何をしているか分かるか。腕と胴の間にすき間（ネガティブスペース）があるか。

### 避けること
| NG | 内容 | 対策 |
|---|---|---|
| ツイニング | 左右の腕・脚が鏡写しの同じ形 | 片方に体重、片腕だけ曲げる |
| 水平な肩と骨盤 | 棒立ちに見える | 逆向きに傾ける |
| 腕が胴に貼りつく | シルエットから腕が消える | 胴との間にすき間を作る、肘を外に出す |
| 接線（タンジェント） | 2つの輪郭がちょうど接する（手先が服の縁にぴったり等） | はっきり重ねるか、はっきり離す |
| 骨の長さが変わる | 曲げた腕・脚が伸びて見える | 9-4 の長さを守る（短くなるのは短縮のときだけ） |

### 可愛い立ちポーズの例（パラメータ）
| ポーズ | 骨盤 | 肩 | 頭 | 腕 | 脚 |
|---|---|---|---|---|---|
| コントラポスト＋ストラップを握る（制作例 v3） | 支持脚側 +6° | 逆に −6° | 肩と逆に +6° | 片手は胸の前でストラップ、片手はバッグに添える | 遊脚の膝を内側へ、かかとを少し上げる |
| 後ろ手 | 水平〜わずか | 少し後ろへ反る | 首をかしげる | 両手を腰の後ろで組む（肘が外に出る） | 片足のつま先を立てる |
| ピース | 支持脚側へ | 逆 | ピース側へ傾ける | 片手を顔の横、もう片手は腰 | 内股 |
| 頬に手 | わずか | わずか | 手の方へ傾ける | 片手の指先を頬へ、肘は胸の前 | 足をそろえて片膝を曲げる |
| 前かがみ（覗き込む） | 後ろへ引く | 前へ | 見上げる | 両手を膝の上・後ろ手 | 膝を軽く曲げる |

## 9-4. ポーズに必要な人体構造

### 骨の長さ（頭の高さ H を単位に、5.4頭身の場合）
| 骨 | 長さ | メモ |
|---|---|---|
| 上腕 | ≒ 1.0H | 肩から肘。肘はウエストの高さ |
| 前腕 | ≒ 0.73H | 肘から手首 |
| 手 | ≒ 0.42H | 実際（顔の長さの約 0.75）より小さめにすると可愛い |
| 大腿 | ≒ 1.38H | 股関節から膝 |
| 下腿 | ≒ 1.2H | 膝から足首 |
| 足の長さ | ≒ 0.85H | 正面では短く見える |

### ポーズを付けるときの決まり
1. **骨は伸び縮みしない**。画面上の骨の長さは、この表の長さ以下（こちらへ向かう骨ほど短く見える＝短縮）。長くなったら破綻。
2. **肘・膝は一方向にしか曲がらない**（約145°まで）。
3. 腕を上げると **肩（鎖骨・肩甲骨）も一緒に上がる**。肩の位置を固定したまま腕だけ上げない。
4. **胸郭と骨盤は2つの硬い箱**、その間（ウエスト）だけが曲がる・ねじれる。
5. 関節の位置に **骨の目印**：鎖骨、肘の骨、膝のお皿、くるぶし（内側が高い）。ドットでは 1〜2px の影で示す。
6. 手首はひねりで前腕の幅が変わる。曲げた腕の肘の内側には皺が溜まる。
7. 足：正面で平らに立つ足は横長の台形、つま先立ちの足は縦長になり、甲が見える。

### 太さの表（肉付け）
骨の中心から外側・内側への距離を、骨の付け根 t=0 〜 先端 t=1 で表したもの（制作例、5.4頭身・H=28.7px）。

| 部位 | 外側 | 内側 | ポイント |
|---|---|---|---|
| 太もも | 6.6 → 5.5 → 3.6 | 5.4 → 4.5 → 3.3 | 外側はなだらか、内側は膝上でふくらむ |
| すね・ふくらはぎ | 3.4 → 3.9（t=0.28）→ 2.0 | 3.2 → 4.3（t=0.18）→ 2.0 | **ふくらはぎは内側が高く大きい** |
| 膝 | 半径 3.5×3.0 の楕円 | | 太ももとすねをつなぐ |
| 袖（上腕） | 4.8 → 4.2 | 同じ | オーバーサイズで腕より太い |
| 袖（前腕） | 4.0 → 5.2 | 同じ | 袖口が広がる（萌え袖） |

## 9-5. AIが骨格から描く手順（制作例 v3 の方法）

`character/draw_mio.py` の実装です。

1. **比率表 → 関節の位置**：頭頂・顎・足裏を決め、9-1 の関係から肩・肘・手首・股・膝・足首の高さを決める。
2. **ポーズ → 関節の座標**：9-3 の手順で、支持脚・骨盤の傾き・肩の傾き・腕の曲げを関節の座標（`POSE`）として書く。
3. **骨の長さを検証**：画面上の骨の長さ ÷ 骨の長さ（`BONES`）が 1.03 を超えないか確認する（`report()`）。
4. **肉付け**：関節をつないだ骨に沿って、9-4 の太さの表で多角形を作る（`segment()`）。関節には楕円を足してつなぐ。輪郭は多数決フィルタで1pxのガタつきを消す（`clean()`）。
5. **胴の傾き**：左右対称に描いた胴を、高さごとに肩の傾き→骨盤の傾きへ角度を変えながら回す（`torso_xf()`）。体重側の脇腹が自然に縮む。
6. **頭と髪**：頭は首の関節を中心に傾ける。髪は顎より下ほど傾きを弱め、毛先が重力で真下に垂れるようにする（`head_xf(grav=True)`）。
7. **重なりの順番**：支持脚 → 遊脚（膝が前に出るので手前）、上腕 → 手 → 前腕（曲げた腕は前腕が手前）。上腕と前腕は **別パーツ** にする（同じパーツだと「く」の字が1つの塊に潰れる）。手前のパーツの輪郭は濃い線にして前後関係を見せる。
8. **検討図を出して確認**：頭の高さの目盛り、骨格、重心線、肩・骨盤の傾きを絵に重ねる（`skeleton_sheet()` → `pose_skeleton_x5.png`）。
9. **計測表を出して確認**：9-0 の表の項目を数値で出し、目安の範囲に入っているか確認する（`report()`）。

## 9-6. チェックリスト

### 比率
- [ ] 頭身が狙いどおり（可愛い系の立ち絵なら 5〜6）
