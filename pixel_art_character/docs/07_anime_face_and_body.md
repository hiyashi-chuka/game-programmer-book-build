# 07. アニメキャラの顔・体の描き方（ドット絵の座標つき）

01（人体構造）を「アニメ的にデフォルメ」し、**具体的なピクセル座標** に落とし込むための資料です。

---

## 7-1. 顔（正面）の構成

頭の高さ H（頭頂〜顎先）を基準にした比率：

| 項目 | 位置・大きさ |
|---|---|
| 頭蓋の幅 | 0.85〜0.9H（アニメは実際より横幅広め、丸い） |
| 頬の最大幅 | 0.85H（目の下あたり） |
| 髪の生え際 | 0.2〜0.25H（前髪で隠れることが多い） |
| 眉 | 0.42〜0.48H |
| 目の上端 | 0.48〜0.52H |
| 目の下端 | 0.72〜0.76H（**目の中心は顔の中心より下**） |
| 目の高さ | 0.22〜0.28H（可愛い系は大きく） |
| 片目の幅 | 0.22〜0.27H |
| 両目の間隔 | 片目の幅の 0.8〜1.0 倍 |
| 鼻 | 0.8H（目の下端すぐ下、点か小さな影） |
| 口 | 0.87〜0.9H（鼻と顎の間の上寄り） |
| 顎先 | 1.0H |
| 耳 | 目の上端〜鼻の高さ（髪で隠れることが多い） |

### 顔の輪郭の作り方（正面）
1. 頭蓋の円を描く（直径 ≒ 0.85H、中心は 0.42H の高さ）
2. 目の高さから下は **頬の膨らみ** を保ちつつ、0.8H あたりから顎へ向けて内側に絞る
3. 顎先は 3〜5px の平ら（または緩い丸み）にする。尖らせすぎると怖く、丸すぎると幼い
4. 輪郭のジャギーは「縦に長い段 → 斜め1:1 → 横に長い段」と単調に変化させる

### 顔の輪郭の段（片側、顎に向かう部分）の例（頬の下〜顎先、半分）
```text
K........    ← 頬の縦の線（段の長さ 3〜4）
K........
K........
.K.......    ← 段の長さ 2
.K.......
..K......    ← 1:1
...K.....
....KK...    ← 横長の段
......KKK    ← 顎先（中央へ）
```

### 3/4 向き（斜め）
- 顔の中心線を向く方向へ寄せる。奥の目は幅を 70〜80% に縮め、顔の輪郭の内側に寄せる。
- 奥側の頬の輪郭は目の横で一度へこみ（こめかみ）、頬で膨らむ。
- 鼻は向く方向へ少し飛び出させ、反対側に影。
- 口も中心線に沿って向く方向へずらし、奥側を短く。

### 横顔
- 目は「く」の字の三角形に近い形、瞳は縦長の楕円の半分。
- 鼻先・唇・顎先を結ぶ線（Eライン）で、唇はその内側。
- 耳は頭の中央より後ろ、顎の角の真上。

## 7-2. 目の配置テンプレート（正面）

```text
   眉           眉
  ___          ___
 /   \  gap   /   \
|  ●  |      |  ●  |   ← 目の中心は顔の中心より下
 \___/        \___/
          ・           ← 鼻
         ‿            ← 口
```
- 両目は **同じ高さ・同じ大きさ**。目頭を目尻より1px低くするとたれ目（優しい）、高くするとつり目（勝気）。
- 瞳（虹彩）の幅は目の幅の 60〜75%。上まぶたが虹彩の上部を少し隠すのが自然。
- 視線をそろえる：両方の瞳を同じ方向に同じpx数だけずらす。

## 7-3. 体（アニメ女性）の構成

### 正面の基本形（マネキン）
- 胸郭：逆三角寄りの卵形。肩はなで肩気味、肩幅は頭幅の 1.6〜1.8倍
- ウエスト：頭幅程度まで絞る
- 骨盤：肩幅とほぼ同じか少し狭い。ヒップの外側のカーブは腰骨の高さで最大
- 脚：股から膝へ内側に寄り（膝の間は 0〜2px）、膝から足首へまっすぐ〜少し外へ
- 腕：上腕はまっすぐ、前腕は肘で少し外へ開く（キャリングアングル）。女性は特にこの角度が分かる

### 立ちポーズで可愛く見せるコツ
| テクニック | 内容 |
|---|---|
| コントラポスト | 片脚に重心、骨盤が傾き、肩は逆に傾く。棒立ち感が消える |
| 内股 | 膝を少し内側に寄せ、つま先を内に向ける。可愛い・控えめ |
| 首かしげ | 頭を5〜10°傾ける。目の高さが左右で1〜2pxずれる |
| 手を体の前に | バッグのストラップを持つ、両手を前で重ねる。腕で胴の輪郭を隠し細く見せる |
| 片手を顔の近くに | ピース、頬に手。顔周りの情報量が増え、視線が顔に集まる |
| 萌え袖 | 袖で手を半分隠す。手を描く難しさも回避できる |

### 手（簡略化）
- 手のひら＝四角、指＝まとめてミトン形。96〜200px サイズでは **指を2〜3本の塊** に分けるだけで十分。
- 手の長さ ≒ 顔の長さの 0.75。小さめに描くと可愛い。
- 拳：四角い塊に、指の境目を影で2〜3本。親指を手前に1つ。

### 足・靴
- 正面の足は三角〜台形。靴は足より一回り大きい。
- 厚底は靴底を2〜3pxの帯で。足首の細さとの対比で脚が綺麗に見える。

## 7-5. 描画順とレイヤー（全身立ち絵）

```text
 1. 後ろ髪（内側 → 外側）
 2. 後ろ側の腕（隠れるなら省略）
 3. 脚（肌）→ ソックス → 靴
 4. 胴（肌：首・鎖骨・デコルテ）
 5. インナー（Tシャツ等）
 6. ボトムス（スカート）
 7. アウター（カーディガン）
 8. 手前の腕（袖 → 手）
 9. 小物（バッグのストラップ → 本体）
10. 顔（肌）→ 耳
11. 顔パーツ（眉 → 目 → 鼻 → 口 → 頬）
12. 横髪 → 前髪 → アホ毛
13. 髪飾り
14. 影 → 輪郭線 → ハイライト → クリーンアップ
```

## 7-6. よくある破綻と直し方

| 症状 | 原因 | 直し方 |
|---|---|---|
| 顔が大人びて見える／怖い | 目が小さい・高い、顎が長い | 目を大きく下へ、顎を短く |
| 幼すぎる | 目が大きすぎ・頬が丸すぎ・首が短い | 首を1〜2px伸ばす、顎を少しシャープに |
| 体が棒っぽい | くびれ・ヒップのカーブがない | ウエストを2px絞り、腰骨で広げる |
| 脚が短く見える | 股が低い、スカート丈が中途半端 | 股を上げる、スカートを膝上15〜20%にする |
| 平面的 | 影が全部の縁に均等（ピロー） | 光源を決めて片側に寄せる、落ち影を追加 |
| 顔が浮いて見える | 首の影がない | 顎の下に落ち影を入れる |
| 髪がヘルメット状 | 頭蓋に沿ったまま、束がない | 外周を束で刻む、毛先を尖らせる、隙間に背景を通す |
| 線がガタガタ | 段の長さが不揃い | 0-2のジャギールールで段を整える |
