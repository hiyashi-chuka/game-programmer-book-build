# 14. 絵を良くするための改良の方法 ― 失敗（v7）の原因と、他の作品・ドット絵の技法から学ぶ

v7（『メイドインアビス』の研究を反映）は「悪化した」という評価でした。この資料では、
1. なぜ悪化したのかを分析し、
2. 他のアニメ・漫画の絵作りとドット絵の技法を調べ、
3. 「描き直すたびに良くなる」ための改良の方法をまとめ、
4. それを v8 に反映しました。

図：
- `character/output/compare_v6_v8.png`：v6 と v8 の全身
- `character/output/face_variants_v8.png`：顔の4案（A＝v6、B＝v8、C＝v8 の顔＋v6 の目の間隔、D＝v7）
- `character/output/face_simplify_v8.png`：単純化の効果（v6／v8 の形だけ／v8＋単純化）

---

## 14-1. v7 が悪化した原因

| 原因 | 内容 | 教訓 |
|---|---|---|
| **一度に変えすぎた** | 顔の形・目の形・目の間隔・口・前髪・横髪・体の大きさ・筋肉の丸さを同時に変えた | どれが悪かったか分からない。**1回に変えるのは1〜2項目** |
| **目が離れすぎ** | 両目の間 ÷ 目の幅 が 1.44（v6 は 0.93） | 子どもの絵柄の比率を年上のキャラにそのまま使うと、ぼんやりした顔になる |
| **目を単純にしすぎた** | まつ毛・差し色・涙袋を取ったので、きらめきが減った | 目は顔の中で一番情報を持つ所。**目以外を単純にして、目は残す** |
| **口が猫口に見えた** | 3px の口は小さすぎて形が読めない | ドット絵では **重要なパーツは小さくしすぎない**（14-2 のドット絵の技法） |
| **体が小さすぎた** | 首から下 0.88 倍でちびキャラ寄り | docs/12 の結論（0.94 倍まで）を守る |
| **参考作品の「比率」だけを真似た** | その作品の可愛さは、比率と **線の柔らかさ・色の少なさ・表情** の組み合わせ | 比率だけ移すと、他の要素との釣り合いが崩れる |

## 14-2. 他の作品とドット絵の技法から分かったこと

### アニメ・漫画の絵作り

| 作品・情報源 | 分かったこと | 取り入れ方 |
|---|---|---|
| 『ぼっち・ざ・ろっく！』（キャラクターデザイン：けろりら） | 当初は線の多い複雑なデザインだったが、最終的に **かなりシンプルにまとめた**。監督の依頼で **線や色分けの少ない、大胆に動かせるデザイン** にした。一方で原作の **デフォルメした顔** の魅力は活かしている | 線と色の段数を減らす。可愛さは形と表情で出す |
| 『葬送のフリーレン』（キャラクターデザイン：長澤礼子） | 演じた声優が「**目元や口元からたくさんのものを感じ取れる**」「大きな表情変化ではなく **細かな表情変化が多い**」と評している | 表情は大きく崩さず、目と口の 1px の違いで出す（ドット絵と相性がよい） |
| 『メイドインアビス』（docs/13） | 円で組み立てた形、柔らかい線、キャラは単純で背景は緻密 | 「丸さ」は残し、比率（目の間隔・体の小ささ）は控えめに使う |
| 京都アニメーション（公式ブログ） | キャラクターの表情、とりわけ **目の描き方** が、観る人に伝わるものを大きく左右する | 目の情報は減らさない |

共通点：**全体は単純に、目と口だけは丁寧に**。情報を「減らす所」と「残す所」をはっきり分けている。

### ドット絵の技法

| 情報源 | 分かったこと |
|---|---|
| Sprite-AI（アニメ風ドット絵） | 読める顔の最小は 32×32、48×48 がちょうどよい。小さいサイズでは目が一番大事で、**太く暗い上まぶた** が一番アニメらしく見える手がかり。**ハイライトは両目で同じ角** に置く（ずれると目を細めているように見える）。髪は **シルエットが先、色は後**（アホ毛や束の形で個性を出す） |
| Medium "pixel-grimoire"（陰影の基礎） | 解像度が低いときは **細部を捨て、意味のあるパーツ（目・口）は大きくする**。強すぎる輪郭線は見た目を悪くするので弱める。コントラストが足りないときは小さな光沢を1点足す。**平らな所は均一な色**、曲面だけをランプに沿って色を変える |
| CLIP STUDIO（デッサンの狂いの見つけ方） | 描いた人でも狂いには気づきにくい。**少し離れて見る・目を細めてシルエットで見る**。斜めの顔は輪郭・鼻・目の位置が少しずれるだけで違和感になる |
| これまでの資料（docs/00） | 孤立ピクセル（周りと色が違う1点）はノイズに見える。手で直すのがドット絵の仕上げ |

## 14-3. 改良の方法（この順で試す）

### 方法1：1回に1〜2項目だけ変え、並べて比べる
- 変える前と後、または複数の案を **同じ大きさで並べた比較画像** を作る（`face_variants_v8.png` のように A〜D 案）。
- 選んでもらった案を次の基準にする。悪化したら1つ前に戻す（v8 は v6 に戻してから変えた）。
- 計測値（`report()`）も一緒に記録し、「良かった時の数値」を残す。

### 方法2：情報を減らす所と残す所を分ける（単純化）
| 減らす | 残す・強める |
|---|---|
| 顔の陰影（光と影の2色にする） | 目（上まぶた・瞳・ハイライト・涙袋） |
| 髪の色の段数（明るい・暗いの2段＋天使の輪） | 口の形（小さくしすぎない） |
| 服の影の一番暗い色（本当に深い所だけ） | シルエット（髪の束・アホ毛） |
| 孤立ピクセル（自動で掃除） | 輪郭線の太さの強弱 |

### 方法3：目のルールを固定する
- 目の大きさは v6 の 8×6（半目くらい）を基準にし、変えない。
- 両目の間 ÷ 目の幅 は **0.9〜1.05**（1.4 は離れすぎ）。
- 太く暗い上まぶた、ハイライトは両目で同じ角、瞳は上下のまぶたに接する。

### 方法4：確認の手順を決める
1. **等倍（1倍）で見る**：拡大図で良くても、実際の大きさで読めないと意味がない。
2. **目を細める（縮小する）**：シルエットと明暗の塊だけで可愛いか。
3. **左右反転して見る**：見慣れによる狂いの見落としを減らす（画像編集でよく使われる確認方法）。
4. 計測値が目安（docs/11〜12 のチェックリスト）に入っているか。

### 方法5：3D の結果を「下絵」として、仕上げを 2D で行う（今後）
- ドット絵の職人は、3D や縮小した絵をそのまま使わず、最後に1px ずつ手で直す。
- このプロジェクトでは、3D で形・陰影・輪郭を作り、**顔（目・眉・口・頬）はスタンプで描き、孤立ピクセルを掃除する** ところまで自動化した（v8）。
- 次の段階として、前髪の束の形・髪の輪郭線・手の形などを、**手で描いたスタンプやマスクで上書き** できるようにすると、職人の仕上げに近づく。

### 方法6：参考作品からは「原理」を、1つずつ移す
- 比率だけ、目の形だけ、など **1つの原理を移して比べる**（方法1）。
- 参考作品の可愛さは「比率＋線＋色＋表情」の組み合わせなので、比率だけを極端に移さない。

## 14-4. v8 で行ったこと

v6 を基準に戻し、方法1〜4に沿って **小さな変更と単純化** を行いました。

| 項目 | v6 | v7 | **v8** |
|---|---|---|---|
| 基準 | — | v6 から大きく変更 | **v6 に戻して小さく変更** |
| 頭身 | 4.75 | 4.45 | **4.75** |
| 顔の丸さ（v6＝0、v7＝1） | 0 | 1 | **0.4** |
| 両目の間 ÷ 目の幅 | 0.93 | 1.44 | **1.01** |
| 目と口の三角形 T | 0.43 | 0.30 | **0.41** |
| 目の形 | 2020年代風 8×6 | 丸い単純な目 7×7 | **v6 と同じ 8×6** |
| 額 | 前髪で隠れる | 前髪を短く | **前髪を少しだけ上げる** |
| 横髪 | 頬に重なる | 外へ大きく | **少しだけ外へ** |
| 体の大きさ | 0.94 倍 | 0.88 倍 | **0.94 倍** |
| 顔の陰影 | 4段 | 4段 | **光と影の2段** |
| 髪の色 | 4段 | 4段 | **2段＋天使の輪（少し広く）** |
| 服の一番暗い影 | 遮蔽のある所すべて | 同左 | **深い所だけ** |
| 髪の中の線 | 深さの差 5.0 以上 | 同左 | **7.5 以上（減らす）** |
| 孤立ピクセル | そのまま | そのまま | **自動で掃除** |

### 単純化の実装（`draw_mio_3d.py`、`SIMPLE=True`）
```python
if SIMPLE:
    lv[face] = 2 if lit else 3                 # 顔は光と影の2色
    lv[hair] = 2 if lv <= 2 else 3             # 髪も2段（天使の輪は別に描く）
    lv[(lv == 4) & ~deep] = 3                  # 一番暗い影は深い隙間だけ
...
img = cleanup(img, gmap)   # 同じパーツの中で上下左右4つと色が違う1px を、周りで一番多い色に置き換える
```

### 結果（`face_simplify_v8.png`）
- 顔と服のざらつき（ノイズの点）が減り、すっきりした。
- 一方で、髪の立体感が少し弱くなった（段数を減らしたため）。天使の輪を広げて補っている。

## 14-5. 次に試す候補（1つずつ）

1. 顔の4案（A〜D）から好みを選んでもらい、それを基準にする。
2. 単純化の有り・無しを選ぶ（髪だけ3段に戻す、という中間案もある）。
3. 前髪の束を手描きのスタンプで上書きし、束の形をはっきりさせる（方法5）。
4. 表情の差分（笑顔・驚き・困り顔）を、目と口の 1〜2px の違いだけで作る（フリーレン的な細かな表情）。
