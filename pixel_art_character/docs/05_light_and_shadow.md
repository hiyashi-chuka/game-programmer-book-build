# 05. 光と影の表現方法

## 5-1. 光の基本用語

| 用語 | 意味 | 絵での扱い |
|---|---|---|
| 主光源（キーライト） | 一番強い光 | 方向を **1つに固定**（通常は左上 or 右上、正面やや上） |
| 環境光（アンビエント） | 空や周囲からの弱い光 | 影を真っ黒にしない理由。影の色を決める |
| 反射光（バウンス） | 地面や近くの物からの照り返し | 影の中の輪郭寄りを少し明るくする（顎の下、腕の下側） |
| リムライト（逆光） | 背後からの光 | 輪郭の縁を1px明るく。キービジュアルや夜景で効果的 |
| ハイライト（鏡面反射） | 光源が映り込む最明点 | 髪・目・唇・光沢素材。肌は控えめ |
| 明暗境界線（ターミネーター） | 光が当たる面と影の面の境目 | セル塗りではここが影の線になる |

## 5-2. 影の2種類

1. **形状影（フォームシャドウ）**：物体が光源に背を向けている面にできる影。円柱なら光と反対側の縦長の帯、球なら三日月形。
2. **落ち影（キャストシャドウ）**：物体が他の面に落とす影。前髪→額、顎→首、腕→胴、スカート→太もも、帽子→顔。
   - 落ち影は **形状影より境界がシャープで、濃い**。
   - 落ち影は「影を落とす物の形」を光と反対方向にずらした形になる。

**アニメ・ドット絵では落ち影が最も重要。** 形状影は省略しても、首の影と前髪の影があればそれらしく見える。

## 5-3. アニメのセル塗り（影の段階）

| 段階 | 名称 | 用途 |
|---|---|---|
| ハイライト | ハイライト／ハイ | 髪の天使の輪、目、唇、光沢 |
| ベース | ノーマル／ベタ | 光が当たる面 |
| 1影 | 1号影・影 | 主な影。面積の 20〜35% |
| 2影 | 2号影・濃い影 | 1影の中のさらに奥まった所（首の顎直下、後ろ髪の内側、脇、スカートの中） |

- 影の形は **硬いエッジ**（ぼかさない）が基本。境界をはっきりさせることでアニメらしくなる。
- 近年のイラストでは、硬い影の上に **ふんわりしたグラデーション（エアブラシ的な色の変化）** を重ねる。ドットでは2〜3色のディザや段階的なベタで代用。

## 5-4. 光源別の影の位置チートシート（光源：左上前方）

### 顔
```text
・額      : 前髪の落ち影（毛先の形をなぞり、右下へ1〜2pxずらす）
・目      : 上まぶたの落ち影が白目の上部に1px
・鼻      : 右側／下側に小さな影1〜3px
・頬      : 右側の頬に縦長の薄い影（省略可）
・顎下〜首: 首全体の上部に顎の形の影。右側が少し長い
・耳      : 耳の内側
```
### 体
```text
・首の右側、鎖骨の下、胸の下（服越しにも）
・腕：右腕の右側、左腕は胴に接する内側
・胴：右側の脇腹、上着の内側（前開きの縁）
・スカート：右側のプリーツの谷、スカートが太ももに落とす影（裾の下に2〜4px）
・脚：右脚の右側、太ももの内側、膝の下、ソックスの縁の下
・靴：右側面、靴底との境目
```
### 髪
```text
・頭頂部の右側（球の形状影）
・束と束の間（くさび形）
・後ろ髪の内側（最も暗い）
・前髪の根元付近（頭頂の丸みの下）
```

## 5-5. 影の色の決め方

1. **影＝ベースを暗くするだけではない**。色相を寒色（青・紫）か、肌なら赤〜赤紫へずらし、彩度は少し上げる。
2. 環境色を混ぜる：屋外の昼なら影に青み、夕方なら紫〜オレンジ、室内暖色照明なら赤み。
3. 全素材の影に **共通の色味（例：紫）** をうっすら入れると画面がまとまる。

### HSVで考えるランプ生成ルール（ベース色 H,S,V から）
| 段階 | 色相 H | 彩度 S | 明度 V |
|---|---|---|---|
| ハイライト | +8〜+15°（暖色側） | −15〜−30% | +10〜+15% |
| ベース | 0 | 0 | 0 |
| 1影 | −10〜−20°（寒色側、肌は赤紫側） | +5〜+15% | −12〜−18% |
| 2影 | −20〜−35° | +10〜+20% | −25〜−35% |
| 輪郭 | −25〜−40° | +10% | −45〜−60% |

※「暖色側」= 黄(60°)に近づける、「寒色側」= 青(240°)・紫(270°)に近づける方向。

## 5-6. ドット絵の影のアルゴリズム（AIが計算で影を付ける方法）

### オフセットマスク法（セル影の自動生成）
1. パーツのマスク M を作る。
2. M を **光源方向へ** (dx, dy) ずらしたマスク M' を作る（光源左上なら dx=-2, dy=-2 程度）。
3. `影 = M かつ (M' に含まれない)` → 光と反対側（右下）の縁に三日月形の影ができる。
4. ずらし量をパーツの大きさに合わせる：頭・胴 2〜4px、腕・脚 1〜2px。
5. 2影は同じ処理をさらに小さなずらし量で影の中に適用 or 手で指定。

### 落ち影の自動生成
1. 影を落とす物 A（例：前髪）のマスクを、光と反対方向に (dx, dy) ずらす。
2. `落ち影 = ずらしたA かつ 受ける物B（額）かつ Aそのものではない`。
3. 顎→首：顔マスクを下に 2〜4px ずらし、首マスクと重なる部分を影に。

### 形状影（円柱：腕・脚）
- 円柱の幅を w として、光と反対側の w/3〜w/4 を影に。端の1pxは反射光として1段戻してもよい（小さいサイズでは不要）。

### ディザリング
- 2色の市松模様で中間色を表す。広い面のグラデーション（空、背景）には有効だが、**キャラの肌・顔には基本使わない**（汚れて見える）。
- 使うなら服の素材感（デニム、ニット）や影の境界の1列だけ。

## 5-7. ハイライトの置き方

| 素材 | ハイライト | 形 |
|---|---|---|
| 目 | 白、光源側上に大1・反対側下に小1 | 丸・楕円・四角（ドットでは2×2〜3×3＋1px） |
| 髪 | 明るい同系色、天使の輪 | 横方向にジグザグの帯 |
| 唇 | 下唇に1px（グロス感） | 点 |
| 肌 | 頬・鼻先・肩先に極少量 | 1〜2px または省略 |
| 光沢素材（エナメル、パテント、金属） | 白に近い色、強いコントラスト | 長い帯＋点、反対側に反射光 |
| 布（コットン・ニット） | 基本なし | 皺の山に1段明るい色 |

## 5-8. 光で雰囲気を変える

| シーン | 主光源 | 影の色 | 効果 |
|---|---|---|---|
| 昼の屋外 | 白〜淡黄、上方 | 青紫 | 爽やか |
| 夕方 | オレンジ、低い横から | 紫〜赤紫 | ノスタルジー、エモさ |
| 夜（街灯・ネオン） | ピンク・水色の2色 | 濃紺 | 都会的、現代風 |
| 室内（カフェ） | 暖色 | 赤茶 | 温かい、日常系 |
| 逆光 | 背後 | 全体が影色、輪郭にリムライト | ドラマチック |

標準の立ち絵（キャラ紹介用）は **左上からの白い光＋紫寄りの影** が最も無難で可愛く見える。
