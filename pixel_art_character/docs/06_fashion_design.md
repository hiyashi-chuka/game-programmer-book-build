# 06. ファッションデザイン

キャラクターの服は「性格・年齢・生活感」を伝える最大の情報源です。ここでは **服を設計するための基礎** と、**2025〜2026年ごろの若い女性のトレンド** をまとめます。

| ライン | 形 | 印象 | 例 |
|---|---|---|---|
| Aライン | 上が細く裾が広がる | 可愛い、ガーリー | フレアスカート、Aラインワンピ |
| Iライン | 縦にまっすぐ細長い | クール、大人っぽい | タイトスカート、ストレートパンツ |

## 6-2. 配色

### 面積比の法則
- **ベースカラー 70%**：最も面積の大きい色（上着など）。白・ベージュ・グレー・ネイビーなど落ち着いた色
- **アソートカラー 25%**：ベースと組む色（スカート、インナー）
- **アクセントカラー 5%**：差し色（バッグ、リボン、靴下のライン、髪飾り）。キャラのテーマカラー

### 配色パターン
| パターン | 内容 | 印象 |
|---|---|---|
| 同系色（トーン・オン・トーン） | 同じ色相で明度違い | まとまり、上品（ベージュ×ブラウン） |
| 類似色 | 隣り合う色相 | 自然、柔らかい（ピンク×ラベンダー） |
| 補色アクセント | 反対色を少量 | 目を引く（くすみ緑の服に赤リボン） |
| トーン統一 | 色相が違っても明度・彩度を揃える | パステル同士、くすみカラー同士で統一感 |
| モノトーン＋1色 | 白黒グレー＋差し色1色 | 都会的、地雷系・ストリート |

### キャラ配色のコツ
- **髪色・瞳の色・服の色を連動** させる（髪がピンク系なら服やアクセにピンクを少し）。
- 肌の近くに白や明るい色を置くと顔が明るく見える（レフ板効果）。
- 顔から遠い靴や靴下は濃い色で引き締めると全身が安定する。

## 6-4. 2025〜2026年ごろのトレンド要素（若い女性）

調査から多く挙がっていた要素:

- **Y2Kリバイバル**：ベビーT（小さめのぴったりT）、ミニスカート、ローライズ、メタリック素材。2026年は一過性ではなく大きな潮流として扱われることが多い。
- **ストリートとの融合**：Y2Kを古着・ストリート要素とミックス（オーバーサイズのパーカー、カーゴ、スニーカー）。
- **韓国（ソウル）スタイル**：シアー（透ける）ニットの重ね着、スエード調の柔らかいレザー（黒・チョコブラウン）。
- **バッグ**：パテントなどの光沢がある **コンパクトなショルダーバッグ**、横長の「イーストウエスト」型。
- 日本の定番テイストも根強い：
  | テイスト | 特徴アイテム |
  |---|---|
  | ガーリー／フェミニン | フリルブラウス、ニットカーディガン、プリーツ・フレアスカート、リボン |
  | 韓国っぽ | オーバーサイズニット、ミニスカート＋ロングブーツ、シアー素材、小さいバッグ |
  | 量産型 | ピンク・白・ラベンダー、フリル、リボン、厚底シューズ、ツインテール |
  | 地雷系 | 黒×ピンク、レース、ハート、厚底、涙袋メイク風の目元 |
  | ストリート | パーカー、カーゴ、キャップ、スニーカー、ショルダーバッグ |
  | きれいめ | シャツ、テーパードパンツ、ローファー |
  | 古着ミックス | 色落ちデニム、カーディガン、柄物 |

## 6-5. コーディネートの組み立て方（キャラ用）

1. **キャラのコンセプト** から「テイスト」を1つ選ぶ（例：ガーリー寄りの韓国っぽ）。
2. **シルエット** を決める（例：Yライン）。
3. **主役アイテム** を1つ決める（例：オーバーサイズのクリーム色ニットカーディガン）。
4. 主役を引き立てる **脇役** を選ぶ（例：白のインナー、ネイビーのプリーツミニ）。
5. **アクセントカラー** を小物で入れる（例：ピンクのミニショルダーバッグ、ヘアクリップ）。
6. **足元で全体を締める**（例：黒の厚底ローファー＋白ソックス）。
7. 情報量のバランス：上半身に情報（ボタン、リブ、バッグ）、下半身はシンプル。

## 6-6. デザインのチェックリスト

- [ ] テイストが1つにまとまっている（3つ以上混ぜていない）
- [ ] シルエットに強弱がある（全身同じ太さになっていない）
- [ ] 配色の主役と差し色がはっきりしている
- [ ] 髪色・瞳色と服の色が響き合っている
- [ ] 小さいサイズ（等倍）でもアイテムの種類が判別できる
- [ ] 服の構造（襟、肩線、ボタン、裾）が物理的に成立している
