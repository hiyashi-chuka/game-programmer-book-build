# 02. 服の皺（しわ）と表現方法

## 2-1. 皺ができる原理

皺は「布が **引っ張られる**」「布が **余って溜まる**」「布が **重力で垂れる**」ときにできます。
まず **支点（布が体に引っかかる・押される点）** を決め、皺はそこから放射状・斜めに伸ばすのが基本です。

### 主な支点（テンションポイント）
| 支点 | 生じる皺 |
|---|---|
| 肩の先 | 肩から胸・脇へ垂れる斜めの皺 |
| 脇の下 | 腕を上げると脇から放射状 |
| 肘の内側 | 曲げると内側にジグザグ・渦状の溜まり |
| 胸のふくらみ | 胸の頂点から脇・下方向へ引っ張り皺、胸の下は布が浮いて影 |
| ウエスト（ベルト・ゴム） | 上下に細かいギャザー（縦の短い皺） |
| 股 | 股からももの内側へ放射状の皺 |
| 膝 | 曲げると膝裏にZ字の溜まり、膝頭は布が張る |
| 足首（裾） | 布が靴に当たって溜まる（スタック） |

## 2-2. 皺の7分類（服を描くときの語彙）

| 種類 | 形 | 出る場所 | ドットでの描き方 |
|---|---|---|---|
| パイプ皺 | 平行な筒状の縦皺 | スカート・カーテン・ロング丈の裾 | 縦の影1〜2px＋隣にハイライト1px、毛先（裾）は波形 |
| ジグザグ皺 | Z字に折れ曲がる | 曲げた肘・膝の内側、ジーンズの膝裏 | 斜めの短い影を交互に配置（＞＜） |
| スパイラル皺 | 円柱に巻きつく斜め線 | 袖、ズボンの脚、ロールアップ | 円柱の輪郭に沿って斜めの細い影を等間隔より少し不揃いに |
| ハーフロック | 曲がり目で布が折れ返る | 肘・膝の曲がり角 | 曲がり角に三角形の影＋折れ返った布の縁にハイライト |
| ダイアパー皺 | 2点間で布が垂れてU字の連続 | 両肩間のケープ、胸元の布、スカーフ | 浅いU字を重ねて描く |
| ドロップ皺 | 支点から真下に垂れる | 吊るされた布、ゆったりした袖 | 支点から下へ広がる影の扇形 |
| 不活性皺（イナート） | 床や面に落ちて止まった布 | 床についた裾、座った時のスカート | 平らで不規則な影の塊 |

## 2-3. 素材ごとの見え方

| 素材 | 皺の量 | 皺の形 | 影 | ハイライト |
|---|---|---|---|---|
| コットン（Tシャツ） | 中 | やや丸い、柔らかい | 中程度のコントラスト | 弱い |
| シャツ（ブロード） | 多 | 鋭く細い、折り目が出る | はっきり | 折り目に細い線 |
| ニット・セーター | 少 | 太く丸い、大きなうねり | ソフト。境界をぼかし気味 | なし。代わりに **リブ編みの縦線**／ケーブル柄 |
| デニム | 中 | 太く硬い、膝裏・股にハチノス | 濃い | 皺の山がフェード（色落ち）して明るい |
| シフォン・チュール | 多 | 細く多い、透ける | 透け：下の色と混ぜた中間色 | 柔らかい |
| レザー（合皮） | 少〜中 | 太い、関節に深い皺 | はっきり | **鋭く強い白ハイライト** |
| サテン・パテント（光沢） | 少 | 大きく滑らか | 強いコントラスト | 帯状の強いハイライト＋反射光 |
| プリーツ（スカート） | — | 規則的な折り山・折り谷 | 谷側が影 | 山側が明るい |

## 2-4. アニメ・ドット絵での皺の扱い

- **皺は「描きすぎない」**。アニメの作画では動かすコストのため、立ち姿の皺は1パーツ2〜4本程度が普通。
- 皺は **影の形** として描く（線で描かない）。三角形・くさび形の影＋片側に1px明るい色で「山」を表す。
- 皺の影は服の1影と同じ色を使う。2影は布の重なり・深い溜まりだけ。
- 光源側の皺は薄く短く、影側は長く濃くすると立体感が出る。

### ドットパターン集（B=ベース, s=影, L=明るい, K=輪郭）

**引っ張り皺（肩→脇へ斜め）**
```text
BBBBBBBB
BBBsBBBB
BBBBsBBB
BBBBBssB
BBBBBBBs
```

**肘の内側のジグザグ（袖）**
```text
BBBBBB
BBsBBB
BBBssB
BBssBB
BBBsBB
BBBBBB
```

**ウエストのギャザー（ゴムで寄せた布）**
```text
KKKKKKKKKKKK   ← ウエストの縫い目
BsBBsBBsBBsB
BsBBBBsBBBsB
BBBBBBBBBBBB
```

**プリーツスカート（正面、光源左上）**
- 折り山＝明るい縦線、折り谷＝影の縦線。裾に向かって幅が広がる（台形）。
- 裾は **ジグザグ** に：山の位置で1px下がり、谷の位置で1px上がる。
```text
LBBsLBBsLBBsLBBs
LBBsLBBsLBBsLBBs
LBBBsLBBBsLBBBsL
LBBBsLBBBsLBBBsL
KLBBBsKLBBBsKLBB   ← 裾。谷の位置で輪郭が少し上がる
.KKKK.KKKKK.KKKK
```

**ニットのリブ（袖口・裾）**
```text
BsBsBsBsBs
BsBsBsBsBs
KKKKKKKKKK
```

## 2-5. 服の構造（縫い目・パーツ）

皺だけでなく **縫い目とパーツの境界** を描くと服らしくなります。

- 襟（えり）：シャツ襟、セーラー、丸襟、Vネック、オフショルダー
- 肩の縫い目：ドロップショルダー（オーバーサイズ）は肩線が二の腕まで落ちる → 今風のゆるさの表現
- 袖：セットインスリーブ（肩にぴったり）、ラグラン（首から斜め）、パフスリーブ（肩にギャザーで膨らみ）
- 前立て・ボタン：中央の縦線＋1px のボタン（2〜3個）
- ポケット、ステッチ（デニムのオレンジステッチ）、ファスナー
- 裾：リブ、フリル、レース、カットオフ

## 2-6. 重ね着の描き方

1. 内側の服 → 外側の服 の順に描く。
2. 外側の服の **縁（開いた前身頃、袖口、裾）の内側に影** を落とす（外の服が内の服に影を作る）。
3. 外側の服は内側より **少し大きく** シルエットを取る（厚みの分）。
4. オーバーサイズのカーディガン・パーカーは、**肩が落ち、袖が手の甲まで来る（萌え袖）**、裾が腰〜お尻を覆う。袖の中ほどに大きなたるみ皺を1〜2本。
