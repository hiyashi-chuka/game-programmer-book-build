# 08. 立体感（ボリューム・奥行き）の出し方

「絵が平面的に見える」を直すための資料です。05（光と影）が **影をどこに置くか** の資料なのに対し、この資料は **なぜ立体に見えるのか、どうすれば立体に見えるのか** を扱い、最後にAIが計算で立体感を付ける方法（8-10）をまとめます。

---

## 8-0. なぜ平面的に見えたのか（制作例 v1 の診断）

`character/output/compare_v1_v2.png` の左（v1）は、次の理由で平面的に見えていました。

| 症状 | 原因 | この資料の該当箇所 |
|---|---|---|
| 影が輪郭線のすぐ内側に 1〜2px しかない | 影の面積が小さすぎて「影」ではなく「太い輪郭線」に見えた | 8-4 |
| どのパーツも明るさがほぼ一定 | 形を球・円柱として考えず、縁だけ暗くしていた（ピロー寄り） | 8-2, 8-3 |
| 髪がヘルメットのように平ら | 髪を「頭という1つの球」として陰影を付けていなかった | 8-5 |
| 胴が板のよう | 服のシルエットで影を付けたため、影が袖の下に隠れた | 8-5 |
| パーツの付け根・すき間が明るいまま | オクルージョン影（接触部の暗さ）がない | 8-2 |
| ソックスの口・スカートの裾が真っすぐ | 線が体の丸みに沿っていない（クロスコンターがない） | 8-7 |
| 輪郭線がどこも同じ濃さ | 線の強弱がない | 8-6 |
| 左右の靴がくっついて1つの塊 | 重なり・すき間による奥行きの手がかりがない | 8-8 |
| 背景との境目が弱い | リムライト（逆光の縁）がない | 8-9 |

## 8-1. 立体に見える仕組み（奥行きの手がかり）

人は次の手がかりから「立体」「奥行き」を感じます。**多く重ねるほど立体的** になります。

| 手がかり | 内容 | ドット絵での使い方 |
|---|---|---|
| 陰影（シェーディング） | 光を受ける面は明るく、背を向ける面は暗い | 光源を1つ決め、形に沿って明暗を分ける（8-2〜8-5） |
| 重なり | 覆っている物が手前、覆われている物が奥 | 腕を胴の手前に、髪を肩の手前に。重なった縁に影 |
| 大きさ | 近い物は大きく、遠い物は小さい | 斜め向きでは奥の目・肩・脚を小さく |
| 線の強弱 | 光側は細く（明るく）、影側は太く（濃く） | 輪郭線の色を明部と影で変える（8-6） |
| クロスコンター | 表面を横切る線が形に沿って曲がる | 裾・袖口・ベルト・ボーダー柄を曲線に（8-7） |
| 空気遠近 | 遠い物ほどコントラストが低く、背景色に近い | 奥のパーツ（後ろ髪の内側、奥の脚）を暗く・低コントラストに |
| 接地影 | 物が床に接する所が一番暗い | 足元に薄い影＋靴底の真下に濃い影 |
| 視点（アングル） | 正面より斜め（3/4）の方が奥行きが見える | 立体感を最優先するなら 3/4 向きで描く（8-8） |

## 8-2. 光の家族と影の家族（明暗の7要素）

デッサンでは、立体の明暗を **光の家族** と **影の家族** に分けて考えます。

| 家族 | 要素 | 説明 |
|---|---|---|
| 光 | ハイライト | 光源が映り込む最も明るい点。素材のつやで大きさが変わる |
| 光 | 直接光（ライト） | 光に正面を向いた面 |
| 光 | ハーフトーン（中間調） | 光に対して斜めの面。明部から影へ移る途中 |
| ─ | 明暗境界線（ターミネーター） | 光が当たる面と当たらない面の境目 |
| 影 | コアシャドウ | 明暗境界線のすぐ影側。**影の中で一番暗い帯** |
| 影 | 反射光（照り返し） | 床や周囲から跳ね返った光で、影の縁が少し明るくなる |
| 影 | 落ち影（キャストシャドウ） | 物が別の面に落とす影 |
| 影 | オクルージョン影 | 2つの面が接する・狭いすき間で、光がほとんど届かない所。**最も暗い** |

### 守るべき明度のルール
1. **影の家族の一番明るい色（反射光）は、光の家族の一番暗い色（ハーフトーン）より暗く。** 混ぜると形が崩れる。
2. コアシャドウは明暗境界線に沿って置き、影の中央〜縁に向かって反射光で少し戻す。
3. 落ち影は **接している所ほど濃く・境界がシャープ**、離れるほど薄く・ぼやける。
4. オクルージョン影は接触線に沿った細い帯。脇の下、太ももの間、首と顎の境目、服の重なり、靴と床。

### ドット絵の段階（ランプ）との対応
| ランプ | 7要素 |
|---|---|
| hi | ハイライト |
| lt | 直接光のうち特に光に正対する面 |
| base | 直接光〜ハーフトーン |
| s1 | 影（反射光を含む）、落ち影 |
| s2 | コアシャドウ、オクルージョン影、深い落ち影 |

小さいドット絵では反射光を独立した色にしないことが多い（s1 に含める）。代わりに **影側の輪郭のすぐ内側にリムライト** を入れると同じ効果が出る（8-9）。

## 8-3. 形を単純な立体に置き換える

複雑な人体も「球・円柱・箱・円錐」の組み合わせとして陰影を考えます。

| パーツ | 立体 | 明暗の出方（光源：左上） |
|---|---|---|
| 頭（髪の塊） | 球 | 左上が明るく、右下へ三日月形に暗くなる |
| 顔 | 角の丸い板（アニメ的デフォルメ） | 正面はほぼ明るいまま、右頬の縁と顎の下だけ影 |
| 首 | 円柱 | 右側に縦の影＋顎の落ち影 |
| 胸郭・胴 | 卵形＋円柱 | 右の脇腹側に縦長の影 |
| 上腕・前腕 | 円柱 | 右側 1/3 が影 |
| 太もも・すね | 円柱（上が太い円錐） | 右側 1/3 が影、内ももは接触部で暗い |
| スカート | 円錐 | 右側が暗く、プリーツの谷が影 |
| 手 | 箱＋円柱（指） | 甲が明るく、指の間と右側面が暗い |
| 靴 | 箱＋球（つま先） | 上面とつま先の左上が明るい、側面が暗い |

### 球の陰影（12×12、光源：左上）
```text
正しい（光源に沿う）        ピロー（NG：縁だけ暗い）
....KKKK....               ....KKKK....
..KKLLBBKK..               ..KKSSSSKK..
.KLLLBBBBsK.               .KSSBBBBSSK.
.KLLBBBBBsK.               .KSBBBBBBSK.
KLLBBBBBBssK               KSBBBLLBBBSK
KLBBBBBBBssK               KSBBLLLLBBSK
KBBBBBBBsssK               KSBBLLLLBBSK
KBBBBBBssssK               KSBBBLLBBBSK
.KBBBBsssddK               .KSBBBBBBSK.
.KsBssssddK.  ←反射光       .KSSBBBBSSK.
..KKssddKK..               ..KKSSSSKK..
....KKKK....               ....KKKK....
L=明 B=ベース s=影 d=コアシャドウ/濃い影
```
- 影は光と反対側にまとめて **太い三日月** にする。縁に沿って細く一周させない。
- 右下の縁の1〜2px を反射光として s に戻すと、球が浮いて見える。

### 円柱の陰影（横断面の明暗の並び）
```text
光源：左
| K | L | L | B | B | B | s | s | d | s | K |
       明部 ← → 境界   影  コア 反射光
```
- 幅 8px の脚なら、明部 4〜5px・影 2〜3px が目安。影が 1px だと線に見える。

## 8-4. 面積とコントラスト

- **明部 : 影 ≒ 6〜7 : 3〜4**。影が 2 割を切ると平面的、半分を超えると暗い絵になる。
- 影の帯は **2px 以上** の幅を取る（96〜200px サイズ）。1px の影は輪郭線と区別がつかない。
- ベースと1影の明度差は、パレットの明度（HSV の V や Lab の L*）で **10〜15% 以上** を目安に。差が小さいと、影を付けても平面に見える。
  - 制作例ではカーディガンの1影を `#e0cfb2` → `#dbc7a6`、2影を `#c2ad92` → `#b9a07f` に濃くした。
- 色数を増やすより **明暗の差を広げる** 方が立体感への効果が大きい。

## 8-5. パーツ別の立体感の出し方

### 頭・髪
1. 髪は最初に **頭全体を1つの球** として明暗を付ける（左上が明るく、右下が暗い）。
2. その上に **束ごとの厚み**（束の間のくさび形の影、束の中央のハイライト）を足す。順番を逆にすると、細かく明暗が散らばるだけで丸く見えない。
3. 天使の輪は球のハイライトの帯。**輪のすぐ下を一段暗く** すると、頭が奥へ回り込む感じが出る。
4. 後ろ髪の内側（顔の横〜首）は奥にあるので一番暗く。インナーカラーも明るさを一段下げる。

### 顔（アニメ顔）
- 顔全体に球の陰影を付けると汚れて見える。**内側は平らで、縁の 3〜4px だけ丸い板** として扱い、影は右頬の縁と顎の下だけにする。
- 立体感は **首の落ち影**（顎の形を写した濃い影）と **前髪の落ち影** でつくる。この2つがあれば顔は立体に見える。

### 胴
- 陰影は服のシルエットではなく、**中身の胴体（胸郭・ウエスト・腰）の形** で決める。オーバーサイズの服は胴より大きく、服の縁で影を付けると影が袖の下に隠れてしまう。
- 前開きの上着は、胴の陰影＋前身頃ごとの厚み（前立ての縁が少し丸まる）を重ねる。
- 上着の縁がインナーに落とす影、袖が胴に落とす影を必ず入れる。

### 腕・脚
- 円柱として右側 1/3 を影に。**行ごとの太さで丸みを計算** すると、太もも・膝・足首のどこでも同じように丸く見える。
- 太ももの内側（脚どうしが接する所）、スカートの裾の真下、ソックスの口の上にオクルージョン／落ち影。

### 服
- 布には **厚み** がある。重なった布の縁には、手前の布が落とす影を 1〜2px。
- 皺は形の上に乗る：明部の皺は浅く（1段だけ暗く）、影の中の皺は深く（さらに1段暗く）。
- 段階（レベル）で管理すると、影の中でも皺やプリーツが見える（色を固定で塗ると影の中で消える）。

### 靴・小物
- 箱として上面＝明、側面＝暗。光沢素材は上面の左上に強いハイライト。
- 左右の靴の間に 1px 以上のすき間を空けると、2つの物として立体的に読める。

## 8-6. 線の強弱で立体感を出す

- **光が当たる側の輪郭は明るい（細く見える）線、影側は濃い（太く見える）線**。ドット絵では線の太さを変えにくいので、色の濃さで強弱を付ける。
- シルエットの外周は内側の線より濃く。外周＞重なりの線＞内部の線の順。
- 手前の物の線は途切れずに続き、奥の物の線は手前の物にぶつかって止まる（T字の交点）。これだけで前後関係が伝わる。

---

## 8-7. クロスコンター（形に沿って曲がる線）

表面を横切る線は、立体の断面の形に沿って曲がります。直線のままだと「平らな板」に見えます。

| 線 | 曲げ方（視点が胸の高さの場合） |
|---|---|
| スカートの裾 | 下に膨らむ弧（中央が 1〜2px 下がる） |
| ソックスの口・袖口・リストバンド | 下に膨らむ弧（脚・腕の中心が下がる） |
| ウエストのベルト・ゴム | 目の高さより下なので下に膨らむ弧 |
| 帽子のつば・カチューシャ | 目の高さより上なので上に膨らむ弧 |
| ボーダー柄・リブ | 胴の丸みに沿って、端ほど詰まり、曲がる |

**規則：目の高さより下の輪切りは下に、上の輪切りは上に膨らむ。**

```text
真っすぐ（平面的）     弧（立体的）
KKKKKKKKKK            KK......KK
BBBBBBBBBB            BBKK..KKBB
                      BBBBKKBBBB
```

## 8-8. 重なり・ポーズ・アングル

陰影の工夫だけでは限界があります。**最も大きく効くのはポーズとアングル** です。

| 方法 | 効果 |
|---|---|
| 3/4 向き（斜め） | 顔と体の「正面」と「側面」が同時に見え、奥行きが一気に出る。奥の目・肩・脚を小さく |
| 重なり | 腕を胴の前に出す、片脚を前に出す、髪を肩の前に垂らす |
| コントラポスト | 重心脚側の腰が上がり、肩が逆に傾く。体に前後のひねりが生まれる |
| 短縮（フォアショートニング） | こちらに向かう腕・脚は短く太く見える。手前の手を大きく |
| 空気遠近 | 奥にあるパーツ（奥の腕・脚、後ろ髪）を一段暗く、コントラストを下げる |
| 接地影 | 足元に影。靴底の真下だけ濃い影を足すと「床に立っている」感が出る |

正面・直立は記号として分かりやすい反面、奥行きの手がかりが最も少ない構図です。正面で描く場合は 8-2〜8-7 を全部使って補います。

---

## 8-9. リムライトと反射光

- **リムライト**：背後からの光で、影側の輪郭の内側が細く明るくなる。背景からキャラクターを浮かび上がらせる。
- ドット絵では、影側（右・下）の輪郭の **1px 内側** を、影色と淡い寒色（空の青 `#dfe6ff` など）の中間色にする。
- 入れるのは影の部分だけ（明部に入れると輪郭がぼやける）。髪・袖・脚・スカートなど面積のあるパーツに。顔には入れない。

## 8-10. AIが計算で立体感を付ける方法（法線推定シェーディング）

画像生成を使わずにコードで描くとき、パーツのマスクから **高さ → 法線 → 明るさ** を計算すると、球・円柱の陰影を自動で付けられます。制作例 `character/draw_mio.py` の実装です。

### 手順
1. **高さマップ**：マスクの各ピクセルについて「縁から何px内側か」（距離 d）を求める。
   - 球：上下左右から測る。円柱：左右方向だけで測る（行ごとの太さで丸める）
   - `t = clip(d / R, 0, 1)`、`h = R × √(1 − (1 − t)²)` で断面を円にする（R＝その形の半径）
   - 顔のように「縁だけ丸い板」にしたいときは R を 3〜4px に固定する
   - 3×3 程度のぼかしを2回かけてジャギーを減らす
2. **法線**：`n = normalize(−∂h/∂x, −∂h/∂y, 1)`
3. **明るさ**：光の向き `L = normalize(−0.55, −0.65, 0.52)`（左上・手前）との内積 `λ = n·L`
   - 下ほど少し暗く（環境光は上から）：`λ −= 0.10 × clip((y − 腰の高さ) / 90, 0, 1)`
   - パーツごとの補正（顔は明るく +、インナーカラーは暗く −）
4. **段階に量子化**：`λ > 0.93 → hi`、`> 0.80 → lt`、`> 0.30 → base`、`> 0.02 → s1`、それ以下 `s2`
5. **形の合成**：1つのパーツの形を複数の立体の重ね合わせで表す
   - 髪：頭全体の球（重み 1.0）＋前髪自身の厚み（0.3）
   - カーディガン：中身の胴（円柱 1.0 ＋ 球 0.4）＋前身頃ごとの厚み（0.35）
   - 脚・ソックス：左右の脚それぞれの円柱（ソックスは脚と同じ形を使い、陰影を連続させる）
6. **オクルージョン**：ピクセルの8近傍に、自分より手前の別パーツがあれば1段暗く
7. **落ち影**：影を落とすパーツのマスクを右下にずらし、受ける側と重なる所を s1 / s2 に
8. **ディテールは段階の上げ下げで**：皺・プリーツの谷 +1、折り山 −1、天使の輪 −2。影の中でもディテールが残る
9. **段階 → 色**：パーツの素材ランプで色に変換
10. **リムライト**：影側の輪郭の1px内側を中間色に
11. **輪郭線**：明部（λ > 0.55）は明るい線、影は濃い線

### 疑似コード
```python
def height(mask, mode, edge=None):
    d = distance_from_edge(mask, horizontal_only=(mode == "cyl"))
    R = edge or (row_max(d) if mode == "cyl" else d.max())
    t = clip((d - 0.5) / R, 0, 1)
    return blur(blur(R * sqrt(1 - (1 - t) ** 2) * mask))

lam = normals(sum(w * height(m, mode) for m, w, mode in part.vol)) @ LIGHT + part.bias
level = quantize(lam)          # 0..4
level[occluded] += 1
level[cast_shadow] = max(level, 3)
color = part.ramp[level]
```

### 注意点
- 服のシルエットで形を作ると、影が隠れた部分に入る。**中身の体の形** で高さを作る。
- 体全体を1つの塊で計算すると、脚の間・腕と胴の間が「つながった1つの膨らみ」になる。**左右の脚・腕は別々の形** で計算して合成する。
- 計算だけでは顔が汚れやすい。顔は縁だけ丸い板にして、立体感は落ち影で付ける。
- 最後に必ず拡大画像を見て、孤立した影ピクセルやガタつきを確認する。

## 8-11. 立体感チェックリスト

- [ ] 光源は1つで、全パーツの影が同じ側（右下）にまとまっている
- [ ] 影の帯は 2px 以上あり、輪郭線と区別できる
- [ ] 明部 : 影 ≒ 6〜7 : 3〜4
- [ ] ベースと1影の明度差が十分（10〜15% 以上）
- [ ] 髪は頭全体が1つの球として明暗が付いている
- [ ] 首に顎の落ち影、額に前髪の落ち影がある
- [ ] 胴の陰影は中身の体の形で付いている
- [ ] 腕・脚が円柱として右側 1/3 が影
- [ ] 接触部（脇、内もも、重なった布の縁、靴と床）が暗い
- [ ] 裾・袖口・ソックスの口が形に沿って曲がっている
- [ ] 光側の輪郭は明るく、影側の輪郭は濃い
- [ ] 奥のパーツは暗く・低コントラスト
- [ ] 影側の縁にリムライトがある（顔以外）
- [ ] 足元に接地影がある
- [ ] （可能なら）3/4 向き・重なり・コントラポストで奥行きの手がかりを増やした

- 明暗の要素（光の家族：直接光・ハイライト・ハーフトーン／影の家族：コアシャドウ・反射光・落ち影・オクルージョン影）：The Drawing Source "Value, Light and Form"、Proko "Practical Guide to Realistic Shading"
- 「影の一番明るい値は、光の一番暗い値より暗く」：Skillshare "10 minutes to better drawing: Values"
- ピローシェーディングの問題と光源を先に決めること：OpenGameArt "Chapter 4: Shadow and light"、Pokebip 「Lexique du pixel-art」
- 立体感は光源を決めて大きな明暗をつかむこと、直接光と反射光の使い分け、影の縁を明るくすること：CLIP STUDIO 公式講座、マイナビニュース
- 線の強弱（明るい部分を細く、影の部分を太く）と、重なりによる奥行き知覚：マイナビニュース、Adobe 「奥行き」の解説
- リムライトで平面的なスプライトに奥行きを出す事例：itch.io devlog "4 things we did to add light and depth to our Pixel Art Game"
