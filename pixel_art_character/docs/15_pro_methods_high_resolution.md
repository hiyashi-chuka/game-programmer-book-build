# 15. 解像度を上げて、プロの描き方を取り入れる（v9 / HD）

「解像度を上げてよい、細部まで検討してよい」という条件で、プロのイラストレーター・アニメーター・ドット絵師の描き方を調べ、**もっと可愛く・自然に** するための方法をまとめました。あわせて、それを実装した HD 版（v9）を作りました。

図：
- `character/output/compare_v8_hd.png`：v8（96×176）、HD 2倍（192×352）、HD 4倍（384×704）を同じ大きさで比較
- `character/output/mio_hd_face_x3.png`：HD の顔（開き・半目・閉じ・にっこり）
- `character/output/mio_hd_x2.png` / `mio_hd_1x.png`：HD 4倍（384×704）の完成画像
- `character/output/mio_hd_idle_x2.gif`：呼吸とまばたき

> 調べ方の注意：この環境では Web ページの本文を開けず、すべて **検索結果の要約** から集めました。数値のうち出典が無いものは【目安】と書いています（ドット絵向けに換算した値）。特定の作家の絵柄は真似せず、共通する原理だけを取り出しています。

## 15-1. なぜ解像度を上げると良くなるのか

| 96×176（v8） | 384×704（HD 4倍） |
|---|---|
| 顔の幅が約 25px、目が 8×6px。目の形・瞳のグラデーション・まつ毛の束を **1px 単位の記号** で表すしかない | 顔の幅が約 100px、目が約 32×24px。上まぶたの太さの変化、まつ毛の束、瞳の上下のグラデーション、ハイライト3つを **形として** 描ける |
| 髪は 2 段の明暗と輪郭線だけ | 毛束の分かれ目（溝）、天使の輪のギザギザ、毛先の細さが出せる |
| 眉・首元・手など、数 px の部品が周りの線に埋もれやすい | 部品どうしの間に余白を取れる |

Octopath Traveler の監督は「ドット絵にぎりぎり見える高解像度」を狙ったと話している（HD-2D）。解像度を上げても、**1px の線・色トレス・少ない色の段数** を守ればドット絵らしさは残る。

## 15-2. プロの描き方：顔

| 項目 | プロの描き方 | HD での実装 |
|---|---|---|
| 目の配置 | 目と目の間は目1個分が基本。低めに置くと幼く見える | 目の中心は v8 と同じ（両目の間 ≒ 目の幅） |
| 上まぶた | **下まぶたより濃く太く、目尻へ太く、目頭は細く**。目尻は少し跳ね上げる | 上まぶたの太さを目尻 1.45 → 目頭 0.4（頭の座標）で変え、目尻の外へ跳ねる |
| まつ毛 | **根元が太く先が細い**束を 2〜3 本。全部平行にせず、中央は上、目尻側は外へ開く | 目尻側に外向き 2 本、中央寄りに上向き 1 本。先へ細くなる形 |
| 白目 | 上まぶたの **落ち影** を入れる（灰色より、赤みや紫みのある色がなじむ） | 白目の上端に淡い藤色 |
| 瞳 | **上が暗く下が明るい** グラデーション。上部に差し色、下部にベースより明るく彩度の高いピンク・紫。瞳孔のまわりは濃い | 瞳を 5 段（上部の暗色・差し色・中間・下部のピンク・最下部の照り返し）＋ふち＋瞳孔 |
| ハイライト | 光源側に大きめの楕円、反対側に小さな光、反射光のそばにも小さな光。目と違う色（水色など）を混ぜると単調にならない。**両目で同じ向き** | 左上に主、右下に副、左下に水色のきらめき。両目とも同じ向き |
| 下まぶた・涙袋 | 下まぶたは上より薄く短く。涙袋は線で描かず、淡い色でふくらみを示す（濃いとクマに見える） | 下まぶたは目尻側だけ淡い色、涙袋は明るい色の細い帯 |
| 目の大きさ | （docs/12）大きすぎると違和感 | 目の高さを 0.93 倍に抑えた |
| 眉 | 前髪に隠れる所は、前髪の上に透かして描く（透け眉）【目安】 | 前髪の上に 95% の濃さで重ねる。前髪の輪郭線と見分けがつく赤みのある茶 |
| 鼻 | 点・くの字の下半分・影だけ。描き込むと浮く | 鼻先の小さな影だけ |
| 口 | 閉じた口は短い線。唇を描くと大人っぽい。開いた口は中を奥ほど暗く、舌は奥から出る三角形、歯は省く | 閉じた口は口角を上げた ∪。にっこりの表情は開いた三日月の口＋舌 |
| 血色 | 頬・目の周り・鼻・耳に、少し赤く彩度の高い色を薄く | 頬に 2 段の楕円。膝にも小さな血色 |
| 色トレス | 目の周りの線は黒でなく、赤みのある茶・ワインレッド | 上まぶたは暗い赤紫、まぶたの下側と目頭側は赤茶 |
| 左右差 | 白目の幅が左右で違うと斜視に見えるので、目の比率はそろえる | 目の形は同じ式から作る。斜め向きの奥の目は顔の丸みで自然に狭くなる |

### 実装の工夫：顔を「頭の表面の模様」として描く
アニメ調の 3D モデルでは、目や口を **顔のテクスチャ** として描く。HD 版も同じ考え方で、
1. 顔の面だけをもう一度レイマーチし、各ピクセルの **頭の座標 (x, y)** を求める（前髪の下でも求まる）。
2. 目・眉・鼻・口・頬を、その座標の **曲線と楕円の式** で塗る。
3. 前髪の上の部分は、透かして塗る（透け目・透け眉）。

こうすると、斜め向きの奥の目は自然に狭くなり、顔の丸みに沿って形が曲がる。スタンプ（固定のドット絵）と違い、**解像度を変えても同じ形で描ける**（2倍でも4倍でも同じプログラム）。

## 15-3. プロの描き方：髪

| 項目 | プロの描き方 | HD での実装 |
|---|---|---|
| 束 | 分け目とつむじから放射状に。太い束と細い束を混ぜ、毛先の向きを少しばらつかせる。束の先どうしをつなげるとボサボサに見えない | v8 の毛束の 3D 形をそのまま使う |
| 束の分かれ目 | 束の境目に影色の切れ込み | 3D の毛束ごとの番号から、束が変わる所に「溝」（今の色と影色の中間）を入れる。濃い線にすると細い糸の束に見えたので弱めた |
| 前髪の塗り | アニメ塗りはグラデーションを使わず、影は生え際・束の下端・側面に硬く入れる | 前髪は束ごとの丸みの縞を消し、ベタ＋落ち影＋束の下の影だけにした |
| 天使の輪 | 頭の丸みに沿った帯。**毛束ごとに反射の角度が違うので形をばらつかせる**。上端は束の形に沿ってギザギザに | 頭頂から頭の高さの約 25% 下に帯。束ごとに高さと幅をずらし、光の側だけに描く |
| ツヤを見せる色 | ベタは明るすぎない方が、明るい帯が映える | 髪の基本色を少し濃いミルクティー色に（`HAIR_HD`） |
| 顔に落ちる影 | 髪の影とは別に「顔に落ちる影」として、光源から逆算して額に落とす | 3D の影の計算で、前髪の影が額にギザギザに落ちる |
| 髪の内側 | 奥の束は 1 段暗く | ボブの内側はインナーカラーで 1 段暗い |

## 15-4. プロの描き方：塗り・光・線

| 項目 | プロの描き方 | HD での実装 |
|---|---|---|
| 肌の影色 | 単に暗くするとくすむ。**赤〜オレンジ寄りで彩度を上げる**。例：肌 #FFECEA → 1影 #EDC1BF → 2影 #D8A29F（1段ごとに彩度 +6〜11、明度 −7〜11） | v8 の肌の色（影は赤み寄り）を使う |
| 影の境目 | **明暗の境目に彩度の高い色**を入れる（明暗境界線）。血色がよく見える | 体の肌の影の境目（明るい側）に 1px の明るいサーモンピンク |
| 光 | 光源は 1 つに統一。輪郭に沿って一律に暗くする「ピロー陰影」は避ける | 左上の光だけで 3D から計算 |
| リムライト | 逆光の縁取り。青白いと月光、暖色だと日光の印象 | 影側の縁に淡い青 |
| 仕上げ | 全体をオーバーレイやグラデーションマップで色調補正 | 上をほんのり暖色、下をほんのり寒色に（数％） |
| 線の色 | 黒でなく、周りの色の暗い版（色トレス）。光が当たる側の外周は明るい線（選択的アウトライン） | 素材ごとの線の色。光の側は影色寄りの明るい線、影側は濃い線 |
| 線の太さ | 外側は太く内側は細く。毛先は細く抜く。ただし小さな絵で強弱をつけすぎるとガタつく | 1px の線を基本に、束の分かれ目は線でなく溝 |
| ディザ | 顔やキャラには使わない（砂のように見える） | 使わない |
| 色の段数 | 64px 以上のキャンバスで 4〜5 段。素材ごとに少ないランプ | 肌・髪・服とも 4〜5 段 |

## 15-5. プロの描き方：体とポーズ

| 項目 | プロの描き方 | HD での実装 |
|---|---|---|
| 重心 | 片足に 7〜8 割。頭・胸・骨盤の傾きをジグザグに（コントラポスト） | v8 のポーズ（肩と骨盤を逆に傾ける）をそのまま |
| 女性らしい立ち方 | 閉じたポーズ。膝を寄せ、つま先を内へ。**膝とつま先は同じ向き** | v8 のまま（遊脚の膝を内へ） |
| 腕 | 脇と肘を閉じ、肘を胴のシルエットの内側に。紐を持つ手は **鎖骨の下〜みぞおち** の高さ【目安】 | v8 では手が首元にあり不自然だったので、みぞおちの高さへ下げて紐を握らせた |
| 手足 | 可愛い系は手足を細く、足首と手首を細く | 脚を少し細くした（`LEG_SLIM`） |
| 首元 | 首は細め、鎖骨はやや見せる | 襟ぐりが広く、肩の上の肌が左右に「翼」のように見えていたので、T シャツで肩の上と鎖骨まで覆い、襟ぐりを狭くした（鎖骨の形が T シャツを突き抜けていた） |

## 15-6. ドット絵のプロの手直し（今後の候補）

3D から作った絵は「手直しの土台」と考えるのがプロのやり方（Dead Cells は 3D から作ったが、手直しをしない代わりにちらつきが残った）。プログラムでできる手直しの候補：

1. **線のダブル（L 字の角）を消す**：線を 1px の斜めのつながりにそろえる。
2. **段差の長さをそろえる**：曲線の段差を 1→2→3 のように単調に増減させる（1-3-1-2 のようなばらつきはジャギーに見える）。
3. **段差の角に中間色を 1px**（手動のアンチエイリアス）。外周は背景が決まらないので控える。
4. **孤立ピクセルを消す**（v8 で実装済み）。

## 15-9. 顔がやつれて見える問題（影の入れすぎ）

4 倍にして細部が見えるようになると、「影のせいでやつれて見える」という指摘がありました。原因と直し方：

| 原因 | 直し方 | 根拠 |
|---|---|---|
| 横髪の落ち影が **頬から顎に大きく** 入り、頬がこけて見えた | 顔の落ち影は **前髪の下の額だけ**（頭の座標で高さ 16 より上）。頬・顎には影を入れない | アニメ塗りでは顔はほぼベタで、影は前髪の下と顎の下（首）に置く |
| 頬の赤みが **目の真下に接して**、目の下の赤み（疲れ・クマ）に見えた | 赤みを少し下・外へずらし、薄く小さく | 涙袋や目の下を濃くするとクマに見える |
| 目頭の赤みが大きく、充血して見えた | 目頭のごく一部だけ、淡い色に | — |
| 顔の輪郭線が濃い赤茶で、頬がへこんで見えた | 顔の輪郭だけ細く柔らかい色に | 外側の線は太くてよいが、顔は柔らかく |
| 顎の横のインナーカラー（濃いピンク）が顔を暗く縁取った | インナーカラーを 1 段明るく、影は紫寄りに | 後ろ髪の内側は寒色で空気感を出す |
| 脚の影がまだらで、膝の赤みが「＋」形の点に見えた | 手足の肌は 2 段（明るい面と 1 本の影）＋すねの細いツヤ。膝の赤みは柔らかい楕円 | アニメ塗りは影を単色の段で表す |

**確認の仕方**：顔を拡大して、①頬に影が入っていないか、②目の下に赤みが接していないか、③目が充血して見えないか、④輪郭が暗く縁取られていないか、を見る。

## 15-10. 髪の質感と輪郭（さらに調べて改良）

「髪の質感や輪郭ももっと良くできる」という指摘を受けて、髪の描き方をさらに調べました。

### 分かったこと
| 項目 | プロの描き方 |
|---|---|
| 束の形 | 断面は円柱でなく **平たいリボン**。細い線だけで描くと糸っぽく、デフォルメの顔と合わない。「シルエット → 太い束 → 中・細い束 → 隙間」の順に |
| 影 | 3D のアニメ調モデルでは、髪の法線を **頭を包む球の法線へ寄せて**、影を束単位ではなく大きな形にまとめる（法線の調整） |
| 毛先 | 筆のように細くなる。一様にギザギザだと単調。毛先の線は細く明るく抜く。前髪の毛先には肌の色を重ねて透けさせる |
| 輪郭の線 | 外周は太く、内側の束の線は細く・途切れさせる。**光の側は細く、影側は太く**。線は隣の色より少し暗い色（色トレス） |
| 天使の輪 | 頭の丸みに沿って、**束ごとに長さや高さを変えたギザギザ（N 字・M 字）**。すぐ下に暗い影を置くと輪が目立つ。純白でなく色の付いた白 |
| 毛流れ | ベタだけでは質感が足りないので、流れに沿った薄い線を少し |
| 後ろ髪の内側 | 暗く大まかに、寒色を入れて空気感 |

### HD 版への反映
1. **毛束の座標**：髪の各ピクセルについて、どの束の、根元から何割の位置か（u）、束の中心から横にどれだけか（v）を求める。3D モデルで髪のテクスチャを束に沿って描くのと同じで、以下はすべてこの座標で描く。
2. **法線を球へ寄せる**（60%）：束ごとの円柱の縞が消え、影が大きな形にまとまった（糸っぽさが一番減った変更）。
3. **毛先を尖らせる**：毛束の最後の部品を少し延ばして先端の半径をほぼ 0 に。丸い指のような毛先が、筆先のような形になった。
4. **束の影と光**：各束の影側の縁を 1 段暗く、光側の縁を少し明るく → 平たい束が重なった立体感。
5. **毛流れの線**：束の中ほどから毛先へ、細い線を 1〜2 本（束ごとに位置をずらす）。
6. **毛先の透け**：先の 12% を明るく、前髪の先には肌の色を混ぜる。毛先の輪郭線も明るく抜く。
7. **天使の輪**：束の中心で太く縁で細いレンズ形を束ごとにずらして並べ、すぐ下に細い影。
8. **輪郭の強弱**：髪の外周は影側だけ 2px、毛先は太くしない。

## 15-11. 顔の輪郭と髪型を作り直す（もっと可愛く）

「顔の輪郭や髪質はもう少し可愛くできる」という指摘を受けて、HD 版専用に顔の形と髪型を作り直しました（`character/output/face_hair_hd_before_after.png`）。

### 何が可愛さを下げていたか
| 部分 | 問題 | 調べた原理（15-2・15-10） |
|---|---|---|
| 顔の輪郭 | 口から顎先までが長く、顎が尖った V 字で大人っぽい。目の下の頬にふくらみが無い | 可愛い顔は丸、頬はふっくら（ぷにっと）、顎は小さく、顎〜頬のラインを鋭くしすぎない |
| 前髪 | 細い束をすだれのように並べた形。量が少なく平たい | 束の太さはそろえず大・中・小。細い線だけだと糸っぽく、デフォルメの顔と合わない |
| 横髪 | カーテンのようにまっすぐ垂れ、毛先は外へ細く広がるだけ。上半分が後ろ髪に隠れていた | 顔まわりの毛で輪郭を包む。毛先は筆先のように細く |
| 後ろ髪 | 細い円柱の束、毛先はすべて外ハネ | 束は平たいリボン。ボブは内巻き 8：外ハネ 2 |

### 直し方
| 部分 | HD 版の形（`face_prims_hd` / `build_hair_hd`） |
|---|---|
| 顔 | 顎先を 0.9 上げて口から顎までを短く（`CHIN_UP`）。顎は幅広く丸く。目の下に **頬のふくらみ**（左右の楕円、`CHEEK_PUFF`）を足し、頬骨の出っ張りは外した |
| 毛束の形 | **平たいリボン**（`Ribbon`：断面が楕円、幅：厚み ≒ 2.5：1、厚みの向きは頭の中心から外向き） |
| 後ろ髪 | 11 束、太さは大小交互。頬の高さでふんわり膨らみ、**毛先は首の方へ内巻き**。外ハネは 2 束だけ |
| 横髪 | 細めのリボン 2 本が、こめかみから頬に沿って下り、先は筆先のように尖って少しだけ顎の方へ。後ろ髪の一番前の束を後ろへずらし、横髪の上半分が隠れないようにした |
| 前髪 | 7 束、大・中・小。束は毛先へ向かって徐々に細くなって尖り、束の間から額が見える |
| 遊び毛・アホ毛 | 遊び毛 2 本だけ、アホ毛 1 本（根元が太く、先は細く） |
| 線 | 髪の中の輪郭線は大きく重なる所だけ。束が別の束の手前に重なる所は、細く明るめの線 |

### 試し方
頭だけを 4 倍で描く `set_window()` を作り、1 回 1 分ほどで案を並べて比べた（docs/14 の「1 回に 1〜2 項目だけ変えて比べる」）。
途中でうまくいかなかった案：前髪の束を太くしすぎると厚い帯（ひさし）になった／頭頂の土台を大きくするとヘルメットに見えた／横髪を太く丸くすると頬の横の塊（耳あて）に見えた。

### 今後の候補
- ボブの毛先の向きを、束ごとにもう少しばらつかせる
- 前髪の束の一部を交差させる

## 15-12. 頭身を下げ、髪に一体感を出す

「もう少し頭身を下げた方がよい」「髪のパーツがバラバラに見える」という指摘への対応です。

| 項目 | 前 | 後 |
|---|---|---|
| 頭身 | 5.0（顎を短くしたため v8 の 4.75 より上がっていた） | **4.5**（頭 1.14 倍、首から下 0.88 倍）。4.6・4.5 を並べて比べ、4.5 が一番可愛かった |
| 首 | 長く見えた | 頭を 1.4 下げて短く |
| 首かしげ | -6° | -3.5°（左右の目の高さの差が「歪み」に見えないように） |

髪がバラバラに見えた原因は、①前髪・横髪・後ろ髪の境目に濃い輪郭線が引かれていた、②前髪だけ塗り方（ベタ）が違った、③束ごとの縁の影や溝が強かった、の 3 つでした。髪どうしの境目は「束の重なり」の弱い線だけにし、塗りをそろえ、明暗は大きな塊で見せるようにしました。

## 15-13. 髪を 2D の「束」として設計して描く（プロの手順）

3D の形から光と影を自動で計算する方法では、何度直しても髪が「溶けたゼリー」「バラバラ」に見えました。プロは髪の束・影・ツヤの形を一つずつ意図して描いています。そこで髪だけは、プロと同じ手順で **2D の形として設計して描く** 方式に変えました（`character/hair2d.py`）。体と服は 3D のまま（立体と光の向きの一貫性のため）。

### 手順
1. **シルエット**：髪全体の外形（頭頂は丸く、頬の高さで一番膨らみ、毛先へすぼまる）と、顔を見せる窓（生え際〜顎）。
2. **大きな束**：後ろ〜横のボブ → 頭頂 → 横髪 → 前髪 の順に重ねる。束は「筆の形」（中心線＋太さの変化、先は尖る）。後ろ〜横の束は **頭頂から毛先まで一続き** に流す（こめかみで途切れると、ボブが頭から切り離された塊＝犬の耳・ヘッドホンに見えた）。
3. **影の形**：束の形を光の方向（左上）へずらし、重ならない部分＝束の右下の縁を影にする。手前の束は奥の髪に影を落とす。髪全体の右下の縁にも影。アニメ塗りで影の形を描くときと同じ考え方で、影の形が束ごとにそろう。
4. **ツヤ**：頭の丸みに沿った帯を、束の芯（細くした束）で切り取る → 束ごとのレンズ形のツヤが並ぶ。帯のすぐ下に細い影。
5. **線**：外形は濃く（光の側は少し明るく）、影側の外形は 2px。束どうしの重なりは細く明るめ。毛先は線を抜く。
6. **前髪が額に落とす影**：前髪の形を右下へずらした形。

### 設計の座標
束は「正面から見た頭の座標」で設計し、頭を包む球面に載せてから 3D の投影で画面に写す。斜め向きでも、奥の側が自然に縮む。

### うまくいかなかったこと
- 頭頂の束が外形からはみ出す → 寝ぐせのように見えた（外形の内側で切り取る）
- 束の根元を「ある高さ」で切り取る → ボブの横に棚のような段差ができた（頭の丸みに沿った楕円で、上半分だけ切る）
- 遊び毛が長い → 触角のように見えた（短く 1 本に）
- ボブの下端が縦にまっすぐ → 四角いヘルメット（頬の高さで膨らませ、毛先は内へ）

## 15-14. プロの目線の講評で直したこと

完成度を上げるため、描いた画像を別の担当に「15 年目のプロのイラストレーター兼アートディレクター」の立場で講評してもらい、指摘を直してはまた講評してもらう、を繰り返しました（講評は拡大画像で部位ごとに確認し、見えたことだけを書く）。2 回目の点数は 52 点（顔だけなら 75 点前後）でした。

### 作品全体の完成度（調べた原理）
| 原理 | 内容 |
|---|---|
| 焦点 | 一番強い明暗差と一番豊かな色を顔に集める。髪の暗い塊が顔より強いと視線を奪う |
| 明度の 3 値 | ぼかすと明・中・暗の 3 つの塊に分かれる（肌・白 T・靴下＝明、カーディガン・髪・背景＝中、スカート・靴＝暗） |
| 描き込みの粗密 | 顔＞手＞上半身の服＞スカート＞脚と靴。情報量が均一だと作為のない絵に見える |
| 仕上げ | グラデーションマップ（暗部は青紫、明部は暖色）を薄く、光源は 1 つに統一 |
| 素人っぽさ | 影の形がランダム、色の濁り、線の太さが一定、黒の多用、左右対称すぎ、輪郭どうしが 1 点で接する |

### 指摘と直し方
| 指摘 | 直し方 |
|---|---|
| 首の下のマゼンタの帯がチョーカーに見える | 髪の内側は髪の暗い色（ピンクはほんの少し） |

| ボブが頭から切り離されたヘッドホンに見える | 束を頭頂から毛先まで一続きに、頬の高さで膨らませて毛先は内へ |
| 手が豆腐の塊・ミトン | 指と指の間に線（手のひらとの境目には引かない） |
| バッグがスカートに埋もれたピンクの板 | 前に出し、フタ（丸い下端）と留め金を描く |
| 紐が胸の途中から生えている | 肩の頂上を越えて背中側へ回す |
| 靴がレンガ | かかと・甲・つま先の 3 つの楕円でつなぎ、つま先は低く丸く、靴底は薄く。甲の帯の縫い目を線 1 本。塗りは 2 段 |

| 靴下の足首が風船 | くるぶしの膨らみを外し、すねから足首へ細い円錐で覆う |

| 目尻が横髪に食い込む | 横髪を外寄り・細めに |
