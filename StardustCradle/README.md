# 星屑のクレイドル ―STARDUST CRADLE―

宇宙コロニーに暮らす中学生の少年少女が、コロニー全体を揺るがす事件に巻き込まれていく
**2DアクションSFジュブナイルRPG**。ドット絵とシンセBGMで描く、ちょっとパンクで少し切ない冒険。

- 舞台：中立シリンダー型コロニー〈クレイドル7〉（星暦0085年）
- 主人公：春瀬カナタ（中2）と水無月ルウ（中2）。白い髪の密航少女ニコ、白い機体のシグ……
- 生身のアクション戦闘 ＋ ロボット（アームド・フレーム）に乗っての機体戦
- 全10章（序章〜終章）＋サブクエスト・ランク戦・収集要素

## 遊び方

**`index.html` をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけ**で遊べます。インストールやビルドは不要です。
（日本語フォント「DotGothic16」をGoogle Fontsから読み込みます。オフラインでも等幅フォントで動作します）

| キー | フィールド | 機体戦 | メニュー |
|---|---|---|---|
| 矢印 / WASD | 移動 | 移動 | カーソル |
| Z / Space / Enter | 話す・調べる・攻撃（連打でコンボ） | ビームライフル（長押し連射・自動照準） | 決定 |
| X / Shift | ダッシュ（無敵時間あり） | ブースト | キャンセル |
| C | スキル | 近接攻撃（EN満タンでオーバードライブ） | — |
| Esc / Q / Tab | メニュー | メニュー | 閉じる |

ゲームパッド、スマートフォンのタッチ操作にも対応しています。
セーブはメニューの「システム」からいつでも（3スロット、ブラウザのlocalStorageに保存）。

## 技術的な特徴

外部ライブラリ・画像ファイル・音声ファイルを**一切使っていません**。すべてコードから生成しています。

- **ドット絵の手続き生成**（`js/art/`）：キャラクター（16×24、4方向×歩行）、会話用ポートレート（64×64、表情10種）、
  ロボット、タイル、3/4見下ろしの建物（屋上の室外機や給水塔、看板、ひさし、ネオン）、小物、イベントCG（円筒コロニーの内側パノラマなど）。
- **ライティング**：コロニー時間（朝・昼・夕・夜）で街の明るさが変わり、夜は街灯・窓・ネオンが灯る。加算合成のブルーム、ブラウン管風フィルタ。
- **音楽**（`js/engine/audio.js`, `js/data/music.js`）：WebAudioの自作シンセ（FMエレピ、パッド、ディストーションギター、ドラム）と
  MMLシーケンサで、シティポップ・シンセウェーブ・パンクロック・オーケストラ風など23曲を演奏。キャラごとに会話音（声）の高さが違う。
- **イベントスクリプト**：ストーリーは `async` 関数で記述（`js/story/`）。マップはASCIIで記述（`js/maps/`）。
