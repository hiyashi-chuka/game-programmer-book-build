# 星屑のクレイドル — シナリオ詳細（ビートシート）

`DESIGN.md` のあらすじを、章ごとの「場面（ビート）」に分解したもの。各章の実装はこれに沿う。
各章は **メイン 2〜3時間ぶんの遊び**（会話・探索・寄り道・戦闘・ミニゲーム）を目標にする。
「おつかい」だけで水増しせず、**キャラクターの掛け合いと、選択肢による小さな分岐（セリフが変わる程度）**で厚みを出す。

## キャラクターの口調メモ
- **カナタ**：一人称「オレ」。のんびり、語尾ゆるい。「なんとかなるって」「マジか」。機械の話になると早口。父の話題では黙る。
- **ルウ**：一人称「あたし」。ぶっきらぼう、男勝り。「ニセモノの空」「っしょ」「バカじゃないの」。照れると怒る。ニコには甘い。
- **ニコ**：一人称「ニコ」。たどたどしい、単語区切り。「ニコ、おなか、すいた」「……星が、ないてる」。食べ物で目が輝く。
- **シグ**：一人称「僕」。淡々、敬語まじり、詩的。「……この世界の空は、まだ落ちていない」。ラーメンを初めて食べて固まる。
- **ポンタ**：一人称「オイラ」。「〜っす」「ぶっひゃー！」。スペック早口。
- **ユイ**：一人称「わたし」。丁寧語、規則重視「校則第14条によると」。動揺すると早口。
- **バルガス先生**：「〜だ！」豪快。「廊下を走るな！走るなら全力で走れ！」甘党。
- **ミミ**：「先輩！」「〜っすよ」「スクープの匂い！」。
- **キョウスケ**：「あぁ？」「……借りは返す」。
- **ばあちゃん（トメ）**：「まずは食いな」「〜さね」「あんたの父ちゃんもね……」。
- **ドク**：「ふん」「若造」「機械は嘘をつかん」。ネジに話しかける。
- **DJリリィ**：「ハロー、クレイドル7の夜ふかしさんたち！」軽快。素は優しい姉。
- **ギル**：「イッツ・ショータイム！」「燃えろォ！」芝居がかり。負けを認めるときは潔い。
- **アイゼン少佐**：「……子供の遊びではない」冷静。後半「私も、守りたいものがある」。
- **ミラージュ／ジン**：寡黙。「……退け」。解放後は「大きくなったな、カナタ」。
- **ヘルミナ**：上品、静かな狂気。「戦争のなかった世界を、あの子に」。
- **マザー**：機械的、ですます調。「オハヨウゴザイマス、クレイドル7ノ皆サン」（カタカナ混じり）。

## 序章「空のない空」（ch0）— 約1.5時間
1. **目覚め**（tome_room）：ばあちゃんの「起きなー！遅刻だよ！」。部屋を調べられる（父の写真、シミュレーターの賞状、窓から見える“向こう側の街”）。父のスパナを持って下へ。
2. **星屑亭の朝**（hoshikuzu）：常連客（工場のおっちゃん等）と会話。ばあちゃんがおにぎりを渡す。「父ちゃんの形見、なくすんじゃないよ」。
3. **登校**（minato→school_yard）：通学路。チュートリアル（移動・調べる）。運河沿いでルウがスケボーで追い抜く「遅いよ、カナタ！」。町の人と軽く会話。バルガス先生が校門で仁王立ち「遅刻1秒前！」。
4. **教室**（classroom）：2年B組の朝。ポンタ、ユイ、クラスメイト紹介。授業：AFシミュレーター実習（**チュートリアル戦闘**：生身の練習ドローン戦 or 簡易機体戦 → `E.battle` で練習ターゲット）。カナタ1位、ルウ2位で火花。ユイの小言。
5. **昼休み**（school_hall 購買）：メロンパン争奪戦（タイミングミニゲーム）。ミミ初登場（取材）。
6. **屋上**（rooftop、CG `rooftop`）：ルウ「この空、全部ニセモノなんだよ」。カナタ「でも、オレらの空だろ」。ルウは本物の空が見たい。二人の夢の対比。
7. **放課後の揺れ**：帰り道（minato）で突然の振動（`E.shake`, `quake`）。マザーの放送「回転調整ノタメ……」。町の人の不安。慰霊碑の前で老人が「10年前と同じ揺れだ」。
8. **夜**（tome_room）：ばあちゃんと夕食、父の話（少しだけ）。DJリリィのラジオ（`E.radio`）：「今日の揺れ、マザーは調整って言ってるけど……スクラップ・ベイに軍用の機体が出入りしてるって噂、知ってる？」→ 第1章へ。

## 第1章「ジャンクヤードの白い影」— 約2時間
1. 翌日の放課後（evening）。ルウを誘ってスクラップ・ベイへ。目的：父の形見の作業機〈ポンコツ号〉（ドクのガレージに預けてある）の部品「ジャイロユニット」探し。
2. **スクラップ・ベイ探索**：ラット・暴走ボットとの初の生身戦（チュートリアル続き：コンボ、ダッシュ）。部品集め（3か所）。
3. **ドク登場**（doc_garage）：「ジンの息子か」。ポンコツ号を見せる。足りない部品のリスト。ネジ（猫）とキューブ（ヘルパーロボ、以後ついてくる？）。スキル「スパーク」をドクの改造スタンガジェットで習得（`E.learn('spark')`）。
4. 夜になる（night）。公安の封鎖。サーチライト、ドローン。**ステルス**区間：公安の見張りを避けて進む（patrol）。
5. **ニコとの遭遇**：コンテナの陰で白い髪の少女。言葉が通じにくい。「……たすけて」。公安隊員とのバトル（guard×2）。
6. **ガードナー出現**：生身では勝てない。絶体絶命。**CG `zephyr`**：白い機体ゼフィールが降り立ち、2機を一瞬で撃破（演出）。
7. 残り1機がニコを狙う。カナタ「ドク！ ポンコツ号、動くか！？」→ 起動シーケンス（タイミングミニゲーム）→ **初の機体戦**（scrap_field、ponkotsu vs guardner×1〜2、ゼフィールが味方）。
8. 勝利後、シグがコクピットから「その子を頼む」とだけ言って去る。ニコを連れて星屑亭へ。

## 第2章「星屑亭の居候」— 約2.5時間
1. ばあちゃん「まずは食いな」。ニコ、ラーメンに感動。ルウも泊まり込み。
2. ばあちゃんの手引きでニコは“遠い親戚”として転入（ユイが書類を不審がる伏線）。
3. **学校生活イベント**：ニコの自己紹介、給食、体育（ドッジボール→タイミング）、ポン湯でポンタの実家（風呂イベント、男女別のギャグ）、ミミの取材から逃げる。
4. **ルウ編**（`E.setChar('ruu')`）：ルウ視点で〈ひだまり園〉へ帰る夜。園の子どもたち。ルウがニコに自分を重ねる独白。リリィ（実は園の先輩）との接点の伏線。
5. 公安の聞き込み開始。アイゼン少佐が星屑亭に来店（ラーメンを食べて帰るだけ、緊張の会話）。
6. ニコが「星の声」を聞いて倒れる。マザーの放送と同期している描写。
7. 不良のキョウスケに目をつけられる → 生身ボス戦（kyosuke）→ 認められる。
8. 問題：ポンコツ号の修理代とニコの身分証の偽造費。ルウ「ジャンク・デュエルに出ようよ」。

## 第3章「ネオン・アリーナ」— 約3.5時間
1. ネオン通りへ（night）。リリィのラジオ局を訪ねる（デュエルの情報）。ゲーセンでシミュレーター（ミニゲーム）。
2. アンダーシェル（shell_lobby）：受付。クラン名を決める（選択肢：「スターダスト」が既定）。参加証。`c3_registered` を立てる（ランク戦解禁）。
3. ギル（ネオン・ジャッカルズ）登場、挑発。
4. **予選**：arena で clanA/junker 戦（ルウはまだ機体なし→観客席から応援）。
5. ドクとばあちゃんがポンコツ号を〈ハルカゼ〉へ改造（`G.state.mech.id='harukaze'`）。ばあちゃんが整備に詳しすぎる伏線。
6. ルウが賞金で格闘機〈ローズハウンド〉を手に入れる（以後、機体戦の味方 `allies:[{mech:'rose'}]`）。
7. シグがアリーナに現れ、クランに加わる（「ここなら、空が落ちる前に会える人がいる」）。
8. 準決勝：jackal 部隊。決勝：**ギルのサラマンダー戦**（boss）。勝利。ギルは潔く称える。
9. 賞金でニコの身分証。祝勝会（星屑亭）。だが観客席にアイゼン少佐の姿が……。

## 第4章「文化祭と公安」— 約3時間
1. 文化祭準備。2年B組は「星屑亭・出張店」。材料集め（町中を回る）、看板作り、ポスター貼り。
2. ユイがニコの書類の不備に気づき問い詰める。カナタたちは真実を話す。ユイは父の部屋で見た「プロジェクト・エコー」の資料を打ち明ける。仲間に。
3. **文化祭当日**（festival BGM）：屋台のラーメン作り（タイミングミニゲームを複数回）、クラスの出し物巡り、ミミの号外、バルガス先生の喫茶、キョウスケのお化け屋敷。
4. 後夜祭の直前、公安が学校に突入。避難誘導。ニコが連れ去られる。
5. 追跡（chase）→ 黒い機体〈ノクターン〉が現れる。**負け戦**（`canLose:true`）。ミラージュ「……退け」。
6. 敗北の夜。ルウの怒り、カナタの無力感。ばあちゃん「泣いたら食いな。食ったら立ちな」。

## 第5章「無重力の迷宮」— 約3時間
1. ユイが総督府通行証を用意。作戦会議（星屑亭）。
2. グリーン・ブロックのメンテナンス・トンネルを開放（green の封鎖が解ける）。
3. **トンネル探索**（ダンジョン、複数マップ）：スイッチ・カードキー、ボット・タレット、ウォーデン（生身ボス）。
4. コア・シャフト（無重力区画）。研究所に潜入（ステルス）。
5. **プロジェクト・エコーの記録**：ニコとシグは同じ実験の被験体。シグの記録の日付は「S.C.0091」——未来。（CG `memory`）
6. ニコ救出。ニコがペンダントをカナタに渡す → スキル「エコー・シールド」（`E.learn('echo')`）、装備 `pendant`。
7. 脱出時にミラージュと再戦（今度は互角で痛み分け／アイゼンの介入で中断）。

## 第6章「ミラージュ」— 約3時間
1. シミュレーターの記録：ミラージュの戦い方が、カナタが憧れた“父の戦闘記録”と同じ。
2. ばあちゃんの告白：ジンは5年前、研究所の事故で死んだことにされた。若いばあちゃん＝“星屑のトメ”と、ジンの写真（`photo`）。
3. 研究所跡（ラボの廃墟）を調べる。父の手紙（`letter`）。
4. ミラージュからの決闘状。**ノクターン戦**（boss、BGM mirage）。仮面を割る。
5. 父・ジンの解放。「大きくなったな、カナタ」。ジンが語るゼロ・リライト計画とシグの正体（書き換えに失敗した別の世界から来た）。
6. シグ「僕の世界では、クレイドル7は落ちた。……今度は、落とさない」。

## 第7章「崩れる空」— 約3時間
1. ヘルミナがマザーを掌握。回転異常・地震・重力異常。ミラーが閉じ、永遠の夜（`time:'night'`/`alarm`）。`E.set('w_evac')` で町は避難状態。
2. 避難誘導（町中の人を助ける・倒壊物・暴走ボット）。避難所での人々の会話。
3. ユイが総督（父）と対決（gov_tower）。非常回線を奪う。
4. アイゼン少佐が真実を知り、公安を子どもたちの側につける（「私も、守りたいものがある」）。ギルのクランも参戦。
5. DJリリィの全コロニー放送（正体はルウの施設の先輩、元エコー被験者）。人々が灯りをともす（CG）。
6. ハルカゼ改（`harukaze2`）完成、`overdrive` 習得。ジンとばあちゃんが整備。
7. 宇宙港を防衛する大規模機体戦（waves）→ 外宇宙へ。

## 第8章「星の歌」— 約3時間
1. 宇宙港から出撃（space BGM、宇宙マップ）。ミラー施設への道中の機体戦。
2. ミラー施設（ダンジョン）：宇宙空間とコロニー外壁。仲間ごとの見せ場（ギル、アイゼン、ルウ）。
3. シグとゼフィールが道を開く（ビット群を引き受ける）。
4. 中心核：スターシード（CG `starseed`）。ヘルミナとの対話。
5. **最終決戦：セラフィム**（final BGM、3段階）。ニコの歌（エコー）がカナタとルウとつながる。
6. ヘルミナに娘の声が届く——「ママ、もういいよ」。

## 終章「ほんとうの空」— 約0.5時間
1. スターシードが閉じる。シグは光の中へ（「また、どこかの空で」）。
2. 朝が来る（CG `dawn`）。町の人々の笑顔（各キャラのその後を巡れる）。
3. ニコが正式な住民に。屋上でカナタとルウ「でも、ここがわたしたちの空なんだよね」。
4. スタッフロール（`E.ending()`）。ラスト、星屑亭に一通の手紙——差出人は「S」。
5. クリア後：`G.state.chapter = 10` にして自由行動（ランク戦・サブクエスト・メモリー集め）。
